# KurumiFRP 素材库

本目录保存 KurumiFRP 的候选素材原图。PNG 原图作为普通仓库文件保存，素材为原始候选，不代表均已选入产品。

- `original/`：原批次，199 张。
- `dual/`：双候选素材，794 张。
- `solo/`：单人主题素材，200 张。
- `index.csv`：按文件编号记录主题、用途和尺寸。
- `catalog/`：各批次提示词和方向说明。

总计 1,193 张。生成请求中另有 7 条被服务端审核拦截，因此没有相应图片。原图保持生成时的文件名。

在主开发聊天中，可根据索引和图片选择素材；实际接入软件时应根据目标位置单独检查、裁切和导出。
