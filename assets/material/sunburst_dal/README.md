## 双档加载机制
- **默认轻量内置**：安装包仅通过 `go:embed` 内嵌压缩后的 `web/assets/s_*.webp` 与调色板优化后的 `web/assets/s_*.gif`（39 项合计仅 **6.03 MB**），构建镜像与 CI 打包均自动跳过 `assets/material/`。
- **WebUI 按需拉取原画包**：用户在 WebUI「应用与画廊」点击「从 GitHub 仓库拉取原画质素材包」时，后端按 `manifest.json` 并发拉取本目录对应的 **85.72 MB** 4K/2K/PNG/GIF 无损原文件并逐张执行 `SHA-256` 校验，零重启即时切换为原画质。
