# KurumiFrp 原画质视觉资源库 (`assets/material/webui_v094/`)

本目录存放经过筛选保留的全部 **35 张时崎狂三原画质插画** 及结构化校验清单，供后续版本实现「在线下载原画质资源包（一键升级 WebUI 超清画质）」功能使用。

## 目录结构与设计说明

- **`originals/`（100% 原始无损字节保存，未经二次重编码）**
  - `16x9_stage/`：11 张 `1376×768` 主舞台与登录页横幅原图（`k_02.jpg` ~ `k_16.jpg`）
  - `3x4_portraits/`：11 张 `896×1200` 实例与隧道卡片竖版封面原图（`k_17.jpg` ~ `k_37.jpg`）
  - `4x3_banners/`：5 张 `1200×896` 板块顶部羽化横幅原图（`k_41.jpg` ~ `k_46.jpg`）
  - `1x1_avatars_stickers/`：8 张 `1024×1024` 节点头像与 Q 版贴纸原图（`k_47.jpg` ~ `k_59.jpg`）
- **`cutouts_hd/`**：7 张 Q 版贴纸在原始分辨率（`1024×1024` / `896×1200`）下的高保真透明背景抠图版本（`k_17.webp`、`k_53.webp` ~ `k_59.webp`），便于客户端升级画质时直接无缝替换透明贴纸。
- **`manifest.json`**：记录每一张素材的 `key`（与 `web/assets/k_<id>.webp` 严格 1:1 对应）、原始宽高、字节大小与 `SHA-256` 摘要。

## 编译体积隔离保证

- `web/embed.go` 仅嵌入 `web/assets/*.webp`（总计约 `2.3 MB`），**不会**将 `assets/` 打包进可执行二进制文件，确保 `kurumi.exe` / `kurumifrp` 安装包保持轻量快速。
- `.dockerignore` 与 CI 构建任务已默认隔离此目录，不影响常规编译与容器镜像体积。
