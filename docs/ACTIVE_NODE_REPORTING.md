# 主动上报节点

「主动上报」是独立的管理员功能：一台工作台接收其他工作台发送的实例摘要，也可把本机摘要发送到一个控制端。它与「节点管理」中由控制端拉取的节点相互独立；主动上报节点不开放给受限账户，也不提供远程控制。每台接收端最多登记 32 个主动上报节点。当前为开发中的源码实现，设备间互通及安装部署尚未完成运行验收。

## 连接两台工作台

1. 在控制端的「主动上报」页面，使用「接收其他节点」登记一台设备。将该节点 ID 和一次性凭据通过安全渠道交给发送端管理员。名称允许重复，应以节点 ID 区分设备。凭据仅显示一次；如果响应丢失或关闭页面，请先核对正确的节点，再轮换其凭据。
2. 控制端管理员配置可信 HTTPS 反向代理，只向工作台转发 `POST /api/node-agent/session` 和 `POST /api/node-agent/report`。上游 `Host` 必须是控制端工作台实际的回环监听地址及端口；工作台不会自动开放公网监听、配置代理或申请证书。
3. 在发送端的「主动上报」页面，用「本机向控制端上报」填写控制端的 HTTPS 来源地址、节点 ID 和凭据。地址不能包含路径、查询或片段。可选开启流量样本共享；默认关闭。保存后上报处于停用状态。
4. 点击「核对解析地址」，独立核对列出的全部 IP 均属于控制端，再确认这些地址并启用上报。发送端使用操作系统信任的证书校验，只连接已确认 IP；若解析出的 IP 集合变化，则停止发送，须停用并重新核对确认。它不跟随重定向，也不使用系统代理。
5. 在控制端刷新列表查看最近接收时间和报告摘要；在发送端刷新设置可查看最近一次收到确认的时间。报告间隔由接收端给出，目前为 30 秒；约 90 秒没有新的已接受报告时，接收端显示近期无报告。

例如，可根据实际域名、证书和回环端口调整以下 Nginx 配置。不要转发其他工作台路径，并避免在代理日志中记录授权请求头：

```nginx
server {
    listen 443 ssl;
    server_name controller.example.com;
    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/private-key.pem;

    location = /api/node-agent/session {
        limit_except POST { deny all; }
        proxy_set_header Host 127.0.0.1:9000;
        proxy_pass http://127.0.0.1:9000;
    }
    location = /api/node-agent/report {
        limit_except POST { deny all; }
        proxy_set_header Host 127.0.0.1:9000;
        proxy_pass http://127.0.0.1:9000;
    }
    location / { return 404; }
}
```

## 状态与授权边界

最近接收时间由接收端记录，并非发送端的采集时间。报告可能延迟，内容是较早的实例快照；近期收到报告或发送端收到确认都不能证明对方此刻在线、代理注册成功或业务可达。无报告不代表没有实例或没有流量。可选流量仅为发送端当前运行代次的样本，不是计费或配额数据。

接收端对已认证的每个节点分别限制建会话和上报请求的总频率：允许短时连续 12 次，此后每 5 秒恢复 1 次额度。超过额度时返回 HTTP 429，不改变已有会话和摘要；发送端会按退避间隔重试，未确认的旧报告仍受原有有效期限制。请求即使因接收端繁忙而未获处理，也会消耗该节点的额度。额度仅保存在接收端本进程中，重启接收端或轮换、撤销、删除该节点凭据后清除。

此限制不覆盖无效凭据，也不能阻止持有效凭据的节点在短时额度内用多个慢请求占满接收端共用的 4 个请求槽；不同节点的慢请求同样可能占满。工作台请求读取有超时，仍应在 HTTPS 反向代理处按部署情况限制连接和请求速率。

控制端只保存各节点凭据的校验值，不保存明文；登记信息保存在本机 `node-agents.json`，不包含在配置导出或加密备份中。最近报告、会话和接收时间只保存在本进程，重启后清除。轮换或撤销会使该节点的旧凭据和会话失效并清除已有摘要；删除还会退役该节点 ID。已经发送或收到的数据不能撤回。签发、轮换、撤销和删除发生断线或超时时，结果可能未知；应刷新并核对，不能仅凭错误认为操作未执行。

发送端使用本机数据密钥加密保存凭据。修改设置会停用上报；仅当地址和节点 ID 均不变时，保存可留空凭据以保留原值。停止、修改或删除设置后，已发出的报告仍可能到达控制端。解析地址确认和启停操作发生断线时也应刷新核对。控制端凭据轮换后，发送端需要填写新凭据并重新启用；撤销接收端凭据才能终止该节点的后续授权。

主动上报的授权与本机账户、现有远程节点读取授权和控制授权相互独立。仅暴露上述两个协议路径；管理员页面及其管理接口仍应仅供本机访问。节点报告不携带控制权限，不能用它代替账户授权或远程操作。
