# 主题素材说明

`web/kurumi.webp` 是 KurumiFRP 使用的时崎狂三同人插画。安装向导图像及图标由同一插画转换生成，以保证主题一致。时崎狂三是《约会大作战》的角色，相关角色权利属于各自权利方；本项目和这些素材均为非官方同人作品，不暗示获得授权或官方关联。

`packaging/windows/ChineseSimplified.isl` 为 Inno Setup 简体中文翻译，来源 [Kira 的翻译项目](https://github.com/kira-96/Inno-Setup-Chinese-Simplified-Translation)，其 MIT 许可证保存在相邻的 `ChineseSimplified-LICENSE.txt`。
