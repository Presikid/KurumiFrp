# 密码加密备份与恢复

## 包含内容

加密备份包含当前实例、规则、密钥、当前核心选择、历史快照及变更记录。备份内包含用于解密实例令牌和 STCP 配对密钥的数据加密密钥，因此必须完整加密。

备份不包含官方 frp 核心二进制文件、工作台登录令牌 access.token、系统安装记录或操作系统服务配置。跨设备恢复后，仍需安装适用于目标系统的 frp 核心，并使用目标设备自己的登录令牌。

## 导出

在「配置中心」中点击「导出加密备份」，输入密码和确认密码，下载 JSON 文件。建议使用至少 16 个字符的强密码，密码与备份文件分开保存。忘记密码将无法恢复文件。

加密方式为 PBKDF2-HMAC-SHA256（600,000 次迭代，随机 16 字节盐）派生 AES-256-GCM 密钥；每次使用独立 12 字节随机 nonce，并通过认证标签校验文件完整性。工作台不持久保存备份密码。

## 恢复

在「配置中心」中点击「恢复加密备份」，选择文件、输入密码并确认覆盖当前配置。系统在解密认证通过后，使用原有导入逻辑验证配置、密钥与快照并持久化。密码错误、文件损坏或版本冲突时，当前配置不变。

恢复会替换当前配置和快照，不会自动重启正在运行的 frp 实例。原进程保持已应用的旧配置；请先检查新的核心兼容性，再安排实例重启。

## 兼容与风险

旧版明文 JSON 导入导出仍然可用，但该格式包含数据密钥，不能作为公开分享文件。加密备份不等于防御已控制本机管理员权限的攻击者；备份密码必须足够强，并注意浏览器下载目录的访问权限。
