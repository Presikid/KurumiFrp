# 密码加密备份与恢复

## 包含内容

加密备份按所选范围包含实例、规则、密钥和快照，以及已保存的外部核心选择和变更记录。备份内包含用于解密实例令牌、私密协议配对密钥和 TCPMUX 密码的数据加密密钥，因此必须完整加密。

备份不包含工作台程序、外部 frp 核心二进制文件、工作台登录令牌 access.token、本机 Webhook 通知设置（包括签名密钥）、节点设置及授权、系统安装记录或操作系统服务配置。默认构建的 frp 核心随工作台提供；跨设备恢复后使用目标设备自己的登录令牌、通知设置和节点授权。旧版导出文件可能包含通知地址，也须按凭据保管。

## 导出

在「配置中心」中点击「导出加密备份」，输入密码和确认密码，下载 JSON 文件。建议使用至少 16 个字符的强密码，密码与备份文件分开保存。忘记密码将无法恢复文件。

加密方式为 PBKDF2-HMAC-SHA256（600,000 次迭代，随机 16 字节盐）派生 AES-256-GCM 密钥；每次使用独立 12 字节随机 nonce，并通过认证标签校验文件完整性。工作台不持久保存备份密码。

## 恢复

在「配置中心」中点击「恢复加密备份」，选择文件、输入密码并确认覆盖当前配置。系统在解密认证通过后，使用原有导入逻辑验证配置、密钥与快照并持久化。密码错误、文件损坏或版本冲突时，当前配置不变。

恢复会替换当前配置和所选文件中的快照，保留本机 Webhook 通知和节点设置并忽略文件中的相应设置。默认内置模式还保留本机的外部核心选择，兼容构建仍按文件中的选择恢复。请先停止全部实例并等待操作结束；恢复后检查配置，再按需启动实例。

## 兼容与风险

0.8 使用数据格式 4。它可以导入符合当前模型的格式 3、4 明文配置和加密备份；新导出的加密备份内容使用格式 4，0.7.1.22 不能直接打开。格式迁移、原始数据保留及降级限制见 [0.8 数据格式说明](SCHEMA_MIGRATION_0.8.md)。

明文配置和快照导出包含数据密钥，不能作为公开分享文件；如需密码保护，请使用加密备份。加密备份不等于防御已控制本机管理员权限的攻击者；备份密码必须足够强，并注意浏览器下载目录的访问权限。

`GET /api/export` 提供明文配置或快照导出；`POST /api/backup/export` 提供密码加密备份，需提交当前 `revision` 和 `password`，并可用 `scope` 和 `snapshot` 指定范围。两种导出均不包含本机通知设置。
