# 客户端连接源地址

frpc 实例可以指定连接服务端时绑定的本机 IPv4 或 IPv6 地址，对应 frp 配置中的 `transport.connectServerLocalIP`。留空使用系统默认选择；填写时不要带端口。本机必须能够绑定该地址，地址族也要与实际连接的服务端地址兼容，否则连接会失败。

当前仅允许在 TCP、WebSocket 和 WSS 传输下设置；KCP 和 QUIC 不支持此项，保存时不会默默忽略。该设置不改变访问本地代理目标或 DNS 服务器时使用的源地址。配置保存在实例草稿中，重启应用后生效，并可随 frpc TOML 导入或导出。

实例还可以调整客户端连接超时、两端 TCP 保活间隔以及多路复用保活间隔。数值 0 使用 frp 默认值；TCP 保活填 -1 表示关闭。KCP 和 QUIC 客户端不使用 TCP 保活选项，关闭多路复用或使用 QUIC 客户端时也不能设置多路复用保活间隔。服务端的 TCP 保活只影响对应 TCP 监听连接，不改变 UDP 传输；修改这些设置需要重启实例。
