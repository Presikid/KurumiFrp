# 客户端连接源地址

frpc 实例可以指定连接服务端时绑定的本机 IPv4 或 IPv6 地址，对应 frp 配置中的 `transport.connectServerLocalIP`。留空使用系统默认选择；填写时不要带端口。本机必须能够绑定该地址，地址族也要与实际连接的服务端地址兼容，否则连接会失败。

当前仅允许在 TCP、WebSocket 和 WSS 传输下设置；KCP 和 QUIC 不支持此项，保存时不会默默忽略。该设置不改变访问本地代理目标或 DNS 服务器时使用的源地址。配置保存在实例草稿中，重启应用后生效，并可随 frpc TOML 导入或导出。

实例还可以调整客户端连接超时、两端 TCP 保活间隔以及多路复用保活间隔。数值 0 使用 frp 默认值；TCP 保活填 -1 表示关闭。KCP 和 QUIC 客户端不使用 TCP 保活选项，关闭多路复用或使用 QUIC 客户端时也不能设置多路复用保活间隔。服务端的 TCP 保活只影响对应 TCP 监听连接，不改变 UDP 传输；修改这些设置需要重启实例。

frpc 可选「使用系统信任库验证服务端 TLS 证书」，对应 `transport.tls.useSystemCa = true`；默认关闭，兼容现有连接。开启后，服务端证书必须受运行 frpc 的操作系统信任，且证书名称匹配配置的服务器地址；若使用 IP 地址，证书需包含对应 IP。验证失败时连接不会降级；配置校验不建立网络连接，不能证明证书可用。内嵌核心支持启用 TLS 的 TCP、WebSocket、WSS、KCP 和 QUIC 连接，不能与关闭客户端 TLS 同时使用；其他运行后端须明确声明并实现该能力才能使用。导出的配置交给外部 frpc 时，须自行确认其支持并实际执行这个字段，不能假设旧核心会验证证书。系统信任库随运行环境而异；工作台默认生成的内嵌 frps 自签名证书不能直接通过系统信任验证，使用此选项前需确认目标已提供可验证的证书。它只验证服务端，不代表已绑定客户端账户。

设置保存在实例草稿，复制实例时保留，并支持 TOML 导入与导出；需重启实例生效。旧版工作台若无法识别新字段会拒绝读取配置，包含该字段的历史快照也受影响；请保留原文件，使用支持此设置的版本或兼容备份，不要用旧版覆盖新配置。

## 链路诊断中的控制端口

链路诊断使用当前草稿中的地址和端口。TCP、WebSocket 和 WSS 客户端使用普通 TCP 连接进行探测；它使用系统 DNS 和系统默认源地址，不沿用实例单独设置的 DNS 或客户端源地址，因此结果可能与实例实际连接不同。可连接只表示该地址上的 TCP 服务接受了连接，不证明它是目标 frps，也不证明 TLS、WebSocket、认证、代理注册或公网业务正常。

KCP 和 QUIC 使用 UDP，不能通过一般的端口连接判断服务是否可用；诊断报告将控制端口标记为 `unsupported`（不可判定），不发送探测，也不算作成功或失败。服务端实例的控制端口检查只检查其主 TCP 监听，不检查额外的 KCP 或 QUIC 监听端口。

服务端绑定 IPv4 通配地址时检查 `127.0.0.1`，绑定 IPv6 通配地址时检查 `::1`；显式回环 IP 原样检查，`localhost` 由系统解析。其他绑定地址不作本机回环检查。即使回环连接成功，也无法据此判断外部网络是否可访问。
