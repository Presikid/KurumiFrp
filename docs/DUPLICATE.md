# 复制实例与连接规则

此功能用于创建备用线路、迁移服务配置或复制相似的 frpc/frps 草稿，不需要重新输入复杂的连接参数。

- 在「运行实例」点击「复制实例」。可以选择同时复制关联规则，复制的规则默认全部停用；不会启动新的进程。
- 在「连接看板」点击「复制规则」，选择当前或其他 frpc 客户端作为目标。副本自动分配新 ID 和不重复的名称，默认停用。
- frpc 副本继承连接目标和已经加密的认证信息，但不会自动继承以后可能添加的启动策略；创建后须确认服务端地址和令牌。
- frps 副本自动选择不与已登记 frps、启用的 Visitor 冲突的 TCP 监听端口，并关闭 HTTP/HTTPS 虚拟主机监听。请在编辑器里自行设置正确端口，且确认操作系统端口尚未被其他进程占用。
- STCP 副本在同一受保护状态数据库中复用原有加密密文，不经浏览器回传明文，复制后应核对配对关系。复制整个实例时保留关联规则原名；跨实例或同实例复制单条规则时自动添加 `-copy` 等后缀。
- 不复制正在运行的进程、PID、日志、状态检查结果或服务器上的实际代理注册状态。所有改动采用一个配置修订提交，可从已有历史快照恢复。

后端 `POST /api/duplicate` 经过原有 Host/Origin、登录鉴权和 revision 乐观锁校验。示例请求：

```json
{"revision": 8, "kind": "instance", "id": "0123456789abcdef", "includeTunnels": true}
```

复制单条规则到其他客户端：`{"revision":8,"kind":"tunnel","id":"0123456789abcdef","targetInstanceId":"fedcba9876543210"}`。

复制仍使用完整状态校验与原子提交，超出 64 个实例 / 512 条规则、冲突或无效的请求不会改变数据库。管理器不探测、不预留实际操作系统端口，不调用 frp，也不新增外部服务或依赖。
