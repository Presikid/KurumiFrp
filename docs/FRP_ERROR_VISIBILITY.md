# 服务端错误详情

服务端实例可选择对 frp 客户端隐藏部分错误详情。默认关闭此选项，保持内置核心的默认行为：相关失败响应会包含原始错误。开启后，控制连接登录、代理注册、无效心跳、工作连接和 Visitor 注册中使用该设置的失败响应返回概述；例如代理注册失败的概述仍可能包含代理名称。

此选项只影响使用 `detailedErrorsToClient` 的错误响应，不保证所有错误或其他信息都被隐藏；日志可能记录详情，但部分错误没有详细日志。保存实例只更新草稿，重启服务端实例后才会生效。客户端可能因此无法直接看到具体原因；排障时可查看有权访问的服务端日志，但日志不一定包含详细原因。

开启时生成的 frps TOML 写入 `detailedErrorsToClient = false`；关闭时省略该项，由核心按默认值 `true` 处理。TOML 导入保留该设置，现有实例的旧编辑器请求如果省略此字段，会保留已保存的值。
