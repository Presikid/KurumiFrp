# 按实例查看实时运行日志

运行记录页面提供实例选择和关键词筛选。可同时填写“包含”和“排除”：每个非空条件按原样作为连续文本匹配，默认忽略大小写，也可选择区分大小写；只有满足包含条件且不含排除内容的行会显示。筛选仅作用于浏览器中已收到的日志，不修改或删除服务端记录。对正在运行且有 `runId` 的实例，页面优先使用 `GET /api/logs/stream?id=<实例ID>&runId=<运行代次>`；浏览器不支持 SSE、连接失败或尚未启动时使用原有 `GET /api/logs?id=<实例ID>` JSON 轮询。实时连接断开后，页面约每 5 秒轮询，并在条件满足时重新尝试实时连接；30 秒未收到流事件时会认为连接中断。页面隐藏、切换实例或页面、登出时关闭旧流。手动刷新会重新同步。状态仍独立轮询，以发现运行代次和实例列表变化。

查看较早的日志时，可选择“跳到最新”更新当前显示并滚动到筛选结果末尾，之后新日志会继续跟随底部。如果选择文本暂时阻止了画面重绘，该操作会显示当前缓冲区的内容，可能取消原有文本选择。

选择“暂停更新”会关闭日志流和日志轮询，保留当前快照供筛选、查看和导出；手动刷新会读取一次并保持暂停。暂停不影响实例运行，选择“继续更新”后重新读取最近 200 行，暂停期间超出窗口的日志无法补回。工作台状态仍会更新；发现实例运行代次变化时，旧快照会清空，可刷新或继续更新后读取新代次。

“导出显示内容”将当前实例、运行代次和筛选条件下已显示的日志保存为 UTF-8 文本，不添加配置变更记录或其他实例的日志；无匹配行时不可导出。选中文本期间界面可能暂停刷新，此时导出的是屏幕上已显示的内容，而不是尚未显示的新行。切换实例或页面、运行代次变化、无权限或登出后会丢弃旧视图。导出只使用浏览器已收到的数据，不新增日志接口；权限撤销前已经发送到浏览器的数据无法收回。日志仍可能包含未知敏感信息，分享前请检查并妥善保管；文件最多包含当前内存窗口的 200 行，不是完整日志或持久审计记录。

两个接口都使用现有同源认证，不在 URL 中放置令牌或会话凭据。轮询响应保留 `lines` 和 `runId`。流先发送 `snapshot`，再发送 `lines`；两者包含 `instanceId`、`runId` 和字符串数组 `lines`。大快照可能拆为一个 `snapshot` 和多个 `lines`，客户端按顺序替换和追加。缓冲窗口被追过时服务端重新发送快照；重连也从新快照开始，不使用 `Last-Event-ID`，不保证补回窗口外日志。`heartbeat` 是空对象，`end` 只包含实例和运行代次。前端只接受当前实例、代次、导航及登录会话对应的响应，保留最近 200 行并在界面中筛选。

日志保存在内存中，按运行代次隔离，最近 200 行可通过轮询或流读取。完整行先移除已有的 ANSI 格式并遮蔽启动配置中已知的凭据；超过 16 KiB 的原始行会被丢弃并显示占位文字。此脱敏不能识别所有未知密钥、编码形式或其他敏感内容，也不是持久审计日志。配置变更仍由状态接口提供，不作为进程日志广播。

服务端限制总共 32 条流、每个实例 8 条，日志写入不等待网络。每个事件的日志文本分批，单次写入最多等待 5 秒；空闲时每 10 秒发送心跳，并在每个数据、心跳及结束事件前重新检查当前会话、实例和运行对象。认证撤销或运行对象变化后，下次检查终止流；已经通过检查、正在传输或已发送到浏览器的流数据和轮询快照无法撤回。关闭工作台会先唤醒日志流，再等待 HTTP 服务器退出。若连接不支持写入期限，实时接口会拒绝该连接，页面改用轮询。

本基线的删除操作要求先停止相关实例，导入、备份恢复及历史恢复要求先停止全部实例。成功删除后清除该实例的旧运行对象；成功替换配置后清除全部已停止的旧运行对象，即便新配置复用了相同实例 ID 也不会重新附着其日志。原有数据迁移和运行代次计数逻辑保持不变。

## 当前日志源和后续接入

工作台使用进程内 frp：每次 `Start` 给该 `RuntimeConfig.RunID` 单独的日志接收器，再经过 manager 的逐行缓冲和脱敏。部分上游依赖仍可能使用进程级日志，隔离与关闭时序尚需真实并发和异常恢复验收。

## 账户权限接入和限制

管理员可查看所有实例的日志；操作员和查看者须同时获得该实例的查看权限与单独的日志授权。空的实例或日志授权列表不代表全部实例。轮询和流式接口均在服务端检查账户身份及实例日志权限；实时流在每帧前重新检查会话、授权和运行对象，不将打开连接时的权限一直沿用。授权规则和状态过滤的细节见[本机账户与权限](PERMISSIONS_0.8.md)。

账户授权变更会等待该账户已获准的请求或当前日志帧完成；已经发送到浏览器或代理的数据无法撤回。删除实例或替换配置前会撤销相关受限账户授权；旧运行对象按上文所述清除，不能因复用实例 ID 重新附着旧日志。页面只列出有日志权限的实例，轮询读取失败时会清空当前日志视图；实时流失败后会转为轮询。

同源页面登录或登出时使用 `BroadcastChannel` 和 `storage` 通知其他页面清空旧视图；成功登录还会撤销请求中携带的旧会话，已建立的旧流在下次检查时结束。浏览器通知可能不可用或延迟，带管理令牌的外部客户端不受浏览器登出影响，并发登录也不能当作多账户隔离机制。会话替换、撤销和授权检查由服务端处理；不要依赖前端通知作为授权保证。
