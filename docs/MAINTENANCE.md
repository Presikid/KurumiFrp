# 维护模式：限制受限账户启停

管理员可在配置中心开启或关闭维护模式。默认关闭；开启后，操作员和查看者不能通过本工作台启动、停止或重启本机实例，也不能预览或执行远程实例的控制操作。原有实例授权保持不变，关闭维护模式后仍按原授权检查。管理员始终可以登录、操作实例并关闭维护模式。

维护模式不停止已有隧道，也不暂停工作台启动时的自动恢复、定时计划或目标工作台接受的独立远程控制授权。状态、日志和已有授权范围内的只读信息仍可查看；配置校验、修改自己的密码和退出登录不受影响。切换前已经通过检查的请求可能继续完成，开启后不会撤销已经受理的操作。

状态独立保存在工作台数据目录的 `maintenance.json`，不包含在配置导出、历史快照或加密备份中。文件缺失时默认为关闭；重新启动会读取已保存的状态。文件损坏、不是普通文件或暂时不可读时，原文件会被保留，受限账户的实例操作暂不可用；管理员仍可使用管理功能。请先保护并检查该文件，修复后在配置中心刷新。保存失败时须重新读取并核对状态，不能仅凭请求失败认定设置未改变。工作台运行期间不监视其他程序直接修改该文件。

管理员通过 `GET /api/maintenance` 读取状态，通过 `POST /api/maintenance` 提交当前观察到的 `expected` 和希望设置的 `enabled` 布尔值。两者不一致时返回冲突，要求重新读取；未知字段或缺少字段会被拒绝。两个接口使用现有本机身份、Host 和 Origin 检查，非管理员不能读取或更改维护设置。维护开启或状态无法确认时，受限账户的实例控制请求会在操作受理前被拒绝。
