# 工作台单点登录

当前源码提供管理员配置界面和公开客户端的登录流程，运行验收尚未完成。默认关闭；本机管理令牌和本地密码登录继续可用。

## 提供方和账户

使用支持授权码、PKCE S256 和 OpenID Connect 的公开客户端。配置包含发行者 HTTPS 地址、客户端 ID，以及提供方的 `sub` 或已验证邮箱与已有本地账户 ID 的明确绑定；不自动创建账户，也不保存客户端密钥。同一类型的匹配值只能绑定一个账户，禁用或到期的账户不能登录。

邮箱绑定接受已验签 ID token 中的 `email` 与布尔值 `email_verified: true`。缺少这些声明时，若尚无 `sub` 绑定，会向提供方发现文档中指定的公网 HTTPS UserInfo 地址发送访问令牌读取邮箱，并要求 UserInfo 的 `sub` 与 ID token 一致、邮箱明确标记为已验证；不会覆盖 ID token 中明确未验证或不一致的邮箱。匹配值完全一致且区分大小写，存在相同用户的 `sub` 绑定时优先使用 `sub`。某些提供方允许重新分配邮箱，新持有者可能因此获得对应账户的权限；无法接受这一风险时请使用固定的 `sub` 绑定。

在提供方注册实际使用的回环回调地址，例如 `http://127.0.0.1:9000/api/oidc/callback`。端口或使用的主机名变化时回调地址也会变化，必须与注册值匹配。发行者、发现文档中的授权、令牌和公钥地址须为公网 HTTPS；不使用系统代理或跟随重定向，证书由系统信任库校验。仅支持需要上述公开客户端模式的提供方。

管理员接口 `GET /api/oidc/config` 读取设置，`POST /api/oidc/config` 使用独立修订号保存完整设置；账户绑定必须指向存在的本地账户。设置单独保存在数据目录的 `oidc.json`，不包含在配置导出或加密备份中。文件损坏时保留原文件并禁用该登录方式，不影响本地登录。修改设置会使既有单点登录会话在下一次请求时失效；已经获准执行的操作不回滚。

管理员可在“本地账户 → 单点登录设置”中填写发行者和客户端 ID，逐项绑定提供方 `sub` 或已验证邮箱与已有账户，再启用并保存。配置窗口显示当前访问地址对应的回调地址。删除本地账户后，原绑定会显示为不存在，管理员必须明确移除或更换该绑定后才能保存。登录页仅在配置启用时显示单点登录按钮；登录失败可继续使用本地登录。

管理员可选配提供方分组与角色上限。配置后，已验签的 ID token 必须包含 `groups` 字符串数组，至少一个组名准确匹配规则才允许登录；多个匹配取最高上限，再与本地账户角色取权限较低者。上限不会增加本地实例或操作授权；本地管理员降为操作员或查看者时不会自动获得实例授权。不配置分组规则时沿用本地角色。组名区分大小写，最多读取 256 个组；不同提供方需自行配置其 ID token 返回该声明，UserInfo 中的分组不会用于授权。提供方分组变化在下次登录时生效，不会实时撤销现有会话；管理员修改本机单点登录设置可使已有单点登录会话失效。

## 登录过程

登录入口通过 `GET /api/oidc/status` 判断是否开启，随后同源 `POST /api/oidc/start` 发起。服务端获取提供方发现文档，创建一次性、五分钟有效的状态、nonce 和 PKCE 验证值，浏览器进入返回的授权地址。回调使用与本机浏览器绑定的 SameSite cookie 和一次性状态，交换授权码并校验 ID token 的签名、发行者、受众、有效期、nonce 及必要的授权方；只有已绑定且当前有效的账户能获得其本地权限。

网络请求不发送本机管理令牌、账户密码或配置文件；提供方能够看到所使用的回调地址、客户端 ID 和登录请求。登录会话最多保持 12 小时，且不会超过 ID token 有效期；工作台重启后会话和未完成的授权请求失效。授权成功或失败会进入现有登录记录，不保存提供方 token。此源码尚未进行真实身份提供方、浏览器及安全运行验收。
