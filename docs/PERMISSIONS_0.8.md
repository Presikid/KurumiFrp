# 本机账户与权限

本机管理员使用密码登录，用户名留空；新数据目录的初始密码为空，旧数据目录尚未设置主密码时沿用原本机管理令牌作为初始密码。桌面快捷方式打开工作台，不签发自动登录凭据；本机管理令牌仍供维护操作使用。管理员可以在“本地账户”页面创建、停用、删除账户，重置密码并分配实例；账户持有人也可以修改自己的密码。本地账户用户名不区分大小写，密码至少 12 字节。账户配置保存在数据目录的 `accounts.json`，不包含在配置导出、加密备份或历史快照中。

管理员可在账户列表对单个本地账户选择“撤销工作台会话”。工作台等待该账户已获准的、受账户门闩保护的请求或当前日志帧完成，再清除当时存在的该账户本机工作台会话；实时日志在后续帧重新检查。管理员撤销自己所属账户时，本浏览器也会返回登录页面。此操作不修改账户、密码或账户修订号，不停用账户，也不撤销本机管理令牌、节点授权、frp 连接或已经受理的后台操作。正在进行的登录和之后使用有效凭据的登录仍可能建立新会话；需要阻止重新登录时，应按需停用账户或重置密码。

撤销请求发生超时、断线或响应无法确认时，操作可能已经完成或仍在处理，账户列表不能证明旧会话是否已撤销。不要自动重试：重试也可能撤销刚建立的新会话。管理员接口使用现有 `POST /api/accounts`，提交 `action: "revoke-sessions"`、目标 `id` 和当前账户 `revision`；成功返回 `ok: true` 及未改变的 `revision`。仅管理员可调用，目标账户或修订号变化时须刷新后核对。

管理员可为本地账户设置可选的 UTC 到期时间；留空表示不限期。到期后新工作台登录被拒绝，已有工作台会话在下次请求或实时日志帧时失效；此前已受理的操作不会自动撤销。延长或清除期限后需重新登录。对已启用下文账户认证的 frps，到期账户的新 frp 登录和工作连接也会被拒绝，已有受管连接会请求关闭。到期判断依赖工作台主机时间，连接关闭受调度和 I/O 影响，不会限制流量或自动产生续费，不能作为完整套餐或计费系统使用。本机管理令牌不受账户到期限制。

管理员可在账户页面为本机 frps 保存账户认证设置，默认关闭。保存只修改配置草稿，须显式启动或重启该实例后才应用；账户页展示的是草稿，不能据此确认当前运行代次采用的认证方式。启用后使用独立签发的 frp 机器令牌，不使用网页登录密码；停用或删除账户、轮换或停用其令牌会请求关闭对应受管连接。单独登记令牌不会改变实例认证方式。

当前账户认证仅适用于内嵌 frps 的直接 TCP/TLS 连接与非分组 TCP 代理，须强制 TLS 并配置服务端证书和私钥；不支持 KCP、QUIC、WebSocket、访客、HTTP/HTTPS 虚拟主机或服务端插件。该模式会关闭 TCP 多路复用；客户端须验证服务端证书，配置 `user` 为账户 ID、`auth.token` 为一次性保存的机器令牌、`transport.tcpMux = false`，并在 `auth.additionalScopes` 中包含 `NewWorkConns`。若服务端启用了心跳认证，客户端还须加入 `HeartBeats`。客户端代理名称使用 frp 的账户用户名前缀。独立 frps 不提供这套账户校验；受管配置预览刻意不能直接用于独立 frps。

管理员可通过 `GET /api/accounts` 获取账户 `revision`、`configRevision` 和当前 `frpInstances`（每项含 `id`、`name`、不含秘密的 `binding`），核对目标后向 `POST /api/accounts` 提交账户 `revision`、目标账户 `id`、本机 frps 的 `instanceId` 和 `action`：`frp-issue` 为没有记录的实例签发，`frp-rotate` 替换已有记录，`frp-disable` 删除已有登记。签发和轮换还须提交刚核对的 `configRevision` 与对应 `instanceBinding`；实例配置或身份变化时返回冲突，须重新核对。停用旧记录不要求实例仍存在。成功返回新的账户 `revision` 和当前 `configRevision`；只有签发和轮换的成功响应包含一次性 `token` 及不含密文的 `credential` 状态，请安全保存令牌。账户对象可包含 `frpTokens`，只列出实例 ID、凭据 ID、版本及状态，不返回令牌或密文。`registered` 仅表示记录能按当前实例身份及数据密钥读取，`needs-reissue` 表示应停用或重新签发；两种状态均不代表 frp 认证已启用。每账户最多登记 64 个实例，已删除实例的旧记录可以停用以释放名额。

凭据与本机 frps 实例的当前 incarnation 绑定；删除后重建、导入或恢复配置会使旧记录需要重新签发。导入还可能更换数据密钥，使旧密文不可读取；旧凭据不可用不会导致普通账户长期无法登录，并发账户写入期间正在验证的登录可能需要重试。令牌只以数据目录密钥加密保存在 `accounts.json`，不会复制到权限模板、配置导出或备份。每次签发或轮换产生新的凭据 ID，旧版工作台可能不认识新增字段；回退前请妥善保管账户数据。

签发、轮换或停用发生超时、断线或保存错误时，结果可能未知，不能自动重试；刷新显示的是当时快照，先前请求仍可能在处理。请核对账户、实例及当前记录，若发生版本冲突再刷新；若账户文件写入被冻结，须安全停止并重启工作台后核对。如果未收到明文，按状态重新签发或轮换；接口不能再次显示原值。签发或轮换提交后会释放锁再返回明文，此时即使管理员会话被撤销，已提交的响应仍可能送达此前已验证的请求方。

轮换、停用、删除或改变账户启用状态及期限时，正常的定向撤销按凭据代次关闭已登记的受管连接和受追踪转发。若关闭未确认或发生清理异常，工作台可能请求停止整个相关实例，其他账户的连接也可能中断。若响应包含 `revocation: "unconfirmed"`，账户或凭据变更已经保存，但旧连接关闭未确认；该账户在对应实例的新认证会被阻止，须核对实例并安全重启工作台。确认完成只覆盖已登记且受追踪的连接，不包含尚未登记的握手；关闭过程受调度和 I/O 影响。账户到期后的连接清理同样不是流量计量或强制配额。

管理员可为每个本机账户设置受管 TCP 代理数量上限，默认不限；填 0 会阻止该账户新增代理。同一账户在本工作台所有受管 frps 上的非分组 TCP 代理共享上限，令牌轮换不会重置占位。设置在线生效，下调只阻止之后的新增请求，已有和已获准但仍在创建的代理不会被关闭。列表中的“已占用”是读取时的快照，包含创建或清理中的代理；关闭未确认时会保守保留占位，直到安全退出工作台。该数字不是 TCP 连接数、流量或计费；关闭代理监听后，已经建立的转发连接可能继续，直到连接关闭或受管控制被撤销。共享令牌模式、其他工作台及独立 frps 不受该上限约束。

管理员可使用 `POST /api/accounts` 的 `frp-proxy-limit` 操作，提交账户 `revision`、账户 `id` 和布尔值 `frpProxyLimited`；启用时另提交 0–1000000 的整数 `frpProxyLimit`，关闭时不提交该值。`GET /api/accounts` 的 `frpProxyLimit` 为 `null` 表示不限，`frpProxyUsed` 为 `null` 表示占位数暂不可读取；它们不代表流量使用量。设置与账户共用版本和文件，旧账户默认不限，旧编辑器未提供此设置时保留原值。旧版工作台可能不认识有限上限字段并拒绝读取账户文件；回退前应备份账户数据，并先取消上限，再核对其他新字段的兼容性。

如果账户文件的实际写入返回错误，本次进程会冻结后续账户文件修改，并在 `GET /api/accounts` 中返回 `accountWritesUncertain: true`；此时列表可能仍是旧内存状态。受管 frp 新登录会被拒绝，工作台会异步请求停止当前受管实例，但不能保证立即停止；普通工作台登录和已有会话可能仍按旧内存账户生效。安全停止并重新启动工作台后，须按重新读取的账户文件核对。令牌写入成功但响应丢失不会设置此标志：明文无法再次显示，须核对当前记录并按需轮换。

账户列表支持按用户名搜索，以及筛选启用、7 天内到期、已到期和停用的账户。临近到期只提示已启用且尚未到期的账户，以读取列表时工作台主机的 UTC 时间判断，不依赖浏览器本地时钟。页面显示该次读取时间；长时间停留后请刷新账户列表查看最新状态。此提示仅用于页面查看，不会发送通知或改变账户状态。

管理员可创建、重命名和删除账户分组，并在账户列表为每个本机账户选择一个分组或设为未分组；列表可按分组筛选。分组本身不改变用户角色、权限、到期时间或实例流量，不代表套餐或计费。删除分组会在同一次保存中将其成员移为未分组，不删除账户或撤销会话。分组与账户一起保存在 `accounts.json`，不包含在配置导出、加密备份或历史快照中；已有账户文件没有分组时按未分组读取。较旧版本可能不认识新增字段并拒绝读取使用过分组的账户文件，回退前请妥善保存账户数据。最多 100 个分组，名称去除首尾空白后为 1–40 个字符、最多 128 字节，不能包含控制字符，同名判断不区分大小写。

管理员可从一个现有账户复制角色、本机实例查看和操作授权、操作项、配置与流量查看权限及本机日志权限，保存为该分组的可选权限模板。这是一份快照，不复制远程授权、密码、启用状态或到期时间；来源账户之后的变化不会自动更新模板。选择分组或修改模板不会自动改变任何账户。创建或编辑账户时须主动点击应用并确认；模板只填入编辑草稿，仍须检查并保存账户后才生效。管理员模板代表全部管理权限。若角色、查看或操作项的变化会影响当前远程授权，页面要求先由管理员手动处理，模板不会自动改写远程授权。

删除实例会从全部模板中移除对应本机授权；导入或恢复配置会清除模板中的全部本机实例授权，避免实例 ID 复用后附着旧权限。模板角色和非实例选项仍保留，管理员可在确认新配置后重新复制模板。清理先于配置写入，即使后续配置写入失败，仍需检查模板和账户授权。此功能不是自动继承权限、用户套餐、流量配额或计费系统。

`GET /api/accounts` 供管理员读取账户及 `groups`；每个账户的 `groupId` 为空时表示未分组，分组可包含 `template`。管理员通过同一接口的 `POST` 和当前账户 `revision` 提交 `group-save`（可选 `id`，空 ID 为新建，`groupName` 为名称；可选 `templateFrom` 指定复制来源账户 ID，空字符串清除模板，省略则保留）、`group-delete`（`id` 为分组 ID）或 `group-assign`（`id` 为账户 ID，`groupId` 为空表示移除归属）。分组操作与账户修改共享修订号，过期编辑返回 409；普通账户编辑未提供 `groupId` 时保留原分组。组及成员的写入与账户同文件完成，无法保存时保留现有内存状态；损坏的账户或分组文件按账户文件错误处理并保留原件。

管理员可在账户页面查看和清空最近 300 条本机登录记录。记录包含时间、已注册账户名称或登录方式、实际 TCP 连接对端和是否成功，不包含密码、令牌、启动凭据或转发请求头；未知用户名不会原样保存。通过 SSH 或反向代理访问时，连接对端通常是代理，而不一定是真实访客地址。为避免重复失败造成大量磁盘写入，连续失败最多每秒记录一条，被略过的次数仅在本次运行期间显示；登录记录不保证完整。记录单独保存在数据目录的 `login-history.json`，不进入配置导出或备份。文件不可读或格式损坏时会保留原件并显示提示，不影响登录。

空的实例授权列表表示无法查看任何实例。管理员可为操作员从查看范围中选择可操作实例，并分别授权启动、停止、重启及配置校验；操作权限同时约束已授权的本机和远程实例，配置校验仅用于本机。任一范围为空即不能执行相应操作。重启会中断实例，失败时实例可能保持停止，授予重启不能保证实例持续运行。升级前已有操作员默认保留原来的操作权限，保存自定义列表后按新列表执行。实例状态的共享缓存先按身份过滤，再计算响应的 ETag；非管理员不会收到其他实例、配置历史快照、全局冲突提示或进程错误详情。获得配置详情权限时，授权实例的普通字段和配置预览包含地址、用户名及管理员填写的文本。运行后端输出可能包含无法可靠识别的敏感内容；日志权限默认关闭，管理员可为可信账户从查看范围中选择允许查看日志的实例。升级前已启用日志权限的账户会保留原有范围；选择自定义范围后按新列表执行。

管理员可分别授予配置详情与流量查看权限，默认保留已有账户的查看范围。未授权配置详情时，状态接口只返回授权实例的标识、名称、类型和运行状态，不返回其规则、地址或计划；未授权流量时，本机流量接口拒绝访问，远程节点状态也不返回共享流量。实例名称、运行状态和单独授权的日志仍可能包含管理员填写的信息；日志授权不受这两个开关控制。

日志页的本机历史默认关闭，管理员明确启用后，仅将新产生并经现有处理的完整日志行写入工作台数据目录。历史使用两份各不超过 1 MiB 的轮转文件，所有实例共享容量；较早记录会被淘汰，积压、写入失败或异常退出可能丢行。历史不是完整审计记录。文件虽经过既有密钥脱敏，仍可能包含敏感信息；新建文件使用 0600 权限，Windows 依赖数据目录的访问控制，已有文件的访问权限需由管理员检查。历史不随配置导出或备份。停用只停止记录并保留已有文件；管理员可在日志页明确清除全部实例历史，运行中的实例可能立即产生新记录。

历史读取沿用实例日志授权，并同时绑定本机实例身份。实例删除后重建、导入或恢复配置使身份变化时，旧身份的日志不能通过新实例读取，并会随轮转淘汰。设置与历史分别保存在数据目录中的 `runtime-log-history-settings.json`、`runtime-log-history.jsonl` 和 `runtime-log-history.old.jsonl`；设置文件损坏时采集保持关闭，原文件保留。网络断开或设置、清除操作超时时，结果可能未确认，应刷新并核对。

获得流量权限的操作员和查看者可在授权实例卡片中查看当前流量和每日流量历史；历史为可能不完整的采样增量，详见[流量历史](TRAFFIC_HISTORY.md)。客户端逐规则流量及服务端逐代理明细包含已应用名称，还须获得配置详情权限；只有流量权限时仍可查看实例总量。这里的流量历史不包含配置历史快照或其他实例的数据。

账户密码使用独立随机盐和 PBKDF2-SHA256 保存。登录和改密限制同时进行的密码计算和失败次数；限制保存在进程内。停用、删除、重置密码或更改账户会撤销该账户的会话。每个账户最多保留四个会话；容量已满时会优先回收空闲的账户会话，为管理员保留登录途径。

删除本机实例前会撤销该实例的授权。导入配置、恢复备份或历史版本前，会撤销所有非管理员本机实例授权；如果后续配置写入失败，授权仍可能已经撤销，需要管理员重新检查。远程授权保留在账户文件中并绑定目标实例身份，目标实例被替换后不会附着到新实例。账户文件无效、不可读或引用不存在的本机实例时，原文件会保留，账户登录和账户修改会停用，本机管理员仍可登录；此时创建或替换实例的操作也会受限，避免旧授权意外附着到新实例。若需重建账户，应先停止程序，将原账户文件移至安全位置，重启后再重新创建账户。

每个 API 方法和路径都必须在权限清单中明确登记，未知接口对所有身份默认拒绝。Webhook、更新安装和备份按管理员权限处理。本机快捷方式需要确认工作台地址，但不会签发自动登录凭据。日志接口额外检查明确的日志权限及实例授权。新增接口时必须补充角色、实例范围和敏感输出检查。

权限更改等待对应账户已获准的请求完成，再撤销会话或授权；其他账户不会因密码计算而被全局阻塞。实时日志连接不持有长期权限锁，每一帧在写入前重新检查会话，单帧写入设有超时。实例删除或配置替换会等待受限账户的在途请求，防止旧授权被复用。已经由管理员启动的独立后台任务不会因会话撤销而自动回滚。

工作台只监听显式回环地址；数据目录、本机管理令牌和运行该程序的系统用户属于同一个本机信任边界。此功能不是多租户操作系统隔离。
