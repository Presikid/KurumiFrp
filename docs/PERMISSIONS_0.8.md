# 本机账户与权限

本机管理令牌和桌面快捷方式仍可作为完整管理员使用。管理员可以在“本地账户”页面创建、停用、删除账户，重置密码并分配实例；账户持有人也可以修改自己的密码。用户名不区分大小写，密码至少 12 字节。账户配置保存在数据目录的 `accounts.json`，不包含在配置导出、加密备份或历史快照中。

| 权限 | 管理员 | 操作员 | 查看者 |
| --- | --- | --- | --- |
| 实例状态、规则、配置预览、配置差异、流量 | 全部 | 授权实例 | 授权实例 |
| 启动、停止、重启、校验 | 全部 | 授权实例 | 禁止 |
| 原始日志及实时日志 | 全部 | 可单独授权，仅限授权实例 | 可单独授权，仅限授权实例 |
| 编辑、诊断、探测、注册状态、导入导出、备份、通知、核心、更新和账户管理 | 允许 | 禁止 | 禁止 |

空的实例授权列表表示无法查看任何实例。实例状态的共享缓存先按身份过滤，再计算响应的 ETag；非管理员不会收到其他实例、历史记录、全局冲突提示或进程错误详情。授权实例的普通字段和配置预览仍包含地址、用户名及管理员填写的文本。运行后端输出可能包含无法可靠识别的敏感内容；日志权限默认关闭，管理员可明确为可信的操作员或查看者开启，且只能读取已授权实例的日志。

账户密码使用独立随机盐和 PBKDF2-SHA256 保存。登录和改密限制同时进行的密码计算和失败次数；限制保存在进程内。停用、删除、重置密码或更改账户会撤销该账户的会话。每个账户最多保留四个会话；容量已满时会优先回收空闲的账户会话，本机管理令牌和启动快捷方式保留恢复途径。

删除实例前会撤销该实例的授权。导入配置、恢复备份或历史版本前，会撤销所有非管理员实例授权；如果后续配置写入失败，授权仍可能已经撤销，需要管理员重新检查。账户文件无效、不可读、引用不存在的实例或包含尚不支持的远端授权时，原文件会保留，账户登录和账户修改会停用，本机管理员仍可登录；此时创建或替换实例的操作也会受限，避免旧授权意外附着到新实例。若需重建账户，应先停止程序，将原账户文件移至安全位置，重启后再重新创建账户；需要保留的远端授权数据应先妥善保存。

每个 API 方法和路径都必须在权限清单中明确登记，未知接口对所有身份默认拒绝。Webhook、更新安装和备份按管理员权限处理，签发启动票据仅接受本机管理令牌的 Bearer 请求。日志接口额外检查明确的日志权限及实例授权。新增接口时必须补充角色、实例范围和敏感输出检查。

权限更改等待对应账户已获准的请求完成，再撤销会话或授权；其他账户不会因密码计算而被全局阻塞。实时日志连接不持有长期权限锁，每一帧在写入前重新检查会话，单帧写入设有超时。实例删除或配置替换会等待受限账户的在途请求，防止旧授权被复用。已经由管理员启动的独立后台任务不会因会话撤销而自动回滚。

工作台只监听显式回环地址；数据目录、本机管理令牌和运行该程序的系统用户属于同一个本机信任边界。此功能不是多租户操作系统隔离。
