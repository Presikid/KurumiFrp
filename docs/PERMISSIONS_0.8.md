# 工作台访问、旧数据与日志

工作台只使用一个全局访问密码，不需要用户名。未设置过主密码的数据目录初始密码为空；已有主密码保持不变。登录后可在界面修改密码。旧版本地账户、分组及单点登录不再用于工作台访问。登录后可管理工作台的全部实例和配置，请保护好密码并限制对运行该程序的系统账户及数据目录的访问。本机管理令牌仍用于本机维护，不应公开。

## 从旧版转换受管认证

使用旧版受管账户认证的 frps 配置会保留，停止操作仍可使用；校验、启动或重启前须在实例编辑器中主动选择转换为普通 frp 共享令牌，输入 8–1024 个 UTF-8 字节、不含 ASCII 控制字符的新共享令牌，两次输入必须一致；确认后保存。客户端必须同步核对新令牌以及客户端与服务端之间的 TCP 多路复用设置。旧受管模式强制关闭该多路复用，转换后的普通模式使用实例现有设置；转换不会自动修改该设置。普通 frp 的协议认证仍可使用。

## 旧账户文件和导入

旧版 `accounts.json` 不会自动删除，普通的新增、删除及历史快照恢复不依赖或改写它。旧账户文件可能包含由当前数据密钥加密的数据，因此普通配置导入或加密备份恢复若要更换数据密钥，而旧账户文件存在或无法确认不存在，将保守拒绝；即使旧文件为空也会被拒绝。使用相同数据密钥的导入不受此项限制。

如确实需要更换数据密钥，请先停止工作台，安全备份现有配置（包含原数据密钥）和旧账户文件；确认不再需要在数据目录中保留该文件后，将它安全移至数据目录外，再重启工作台并重新导入。备份和旧文件应妥善保护，不要公开。配置替换可能改变实例身份；回退旧版前还须独立核对旧账户授权，避免旧授权附着到替换后的实例。旧文件保留并不保证旧版凭据或授权仍可直接使用。

## 日志边界

登录工作台后可查看本机实例日志。运行日志可能包含地址等敏感信息，即使经过已有的脱敏处理也应妥善保管。短期本机历史默认关闭；启用后仅记录新日志，所有实例共享两份各不超过 1 MiB 的轮转文件。较早记录会被淘汰，积压、写入失败或异常退出也可能丢失记录，不能视为完整审计。停用会保留已有历史，可在日志页主动清除；日志历史不随配置导出、历史快照或加密备份迁移。
