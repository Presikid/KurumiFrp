# KurumiFRP 0.2.0 预览版

- WebUI 官方 frp 核心管理：稳定版本、运行主机平台自动识别、平台下拉选择、官方下载入口。
- 后台下载、字节进度、取消、SHA-256 校验、ZIP/tar.gz 安全提取、ELF/PE/Mach-O 架构检查。
- frpc/frps 成对版本目录与原子活动指针；启用前检查文件和版本；运行中的实例阻止切换；保留旧版。
- Windows 双击 Install.cmd；Linux 一条安装命令；不需要编译工具或 Docker，不修改系统网站或防火墙。
- 用户级安装、自动端口选择、一次性浏览器登录、退出程序按钮。
- CI 测试通过后发布四个平台的预编译安装包及 SHA256SUMS。

这是本机管理预览版。Windows ARM64/Linux ARM64 交叉编译，不代表原生硬件端到端验收。尚未实现远程设备管理、实例自动开机启动、跨实例配额和定时策略。核心程序的选择切换与管理器自身升级是两个独立流程。
