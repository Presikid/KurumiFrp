# KurumiFRP 0.3.0 预览版

- 安装成功并通过本机 API 检查后，自动清理经清单验证的解压安装文件。
- 内容级核对原始 ZIP/tar.gz 后清理来源；在线一条命令安装记录准确下载路径，成功后删除临时目录。
- Windows 当前用户“已安装的应用”卸载入口和 Uninstall.cmd；Linux kurumifrp-uninstall。
- 确认后删除本安装的程序、配置、密钥、历史、核心、日志、快捷方式、启动项、用户服务和卸载项。
- 认证退出及进程停止确认；启动防竞争标记；无法确认停止或遇到外部集成冲突时不谎报成功。
- 不沿符号链接或 Windows junction 清理外部文件，不按进程名清理其他 frp。
- 增加安装、重复安装、原始包删除、退出失败保留、真实托管测试子进程退出和卸载残留检查。

清洁卸载针对应用自己管理的文件与集成项，不承诺清除系统日志、浏览器历史、备份、用户另存导出或取证痕迹。改名/移动且未明确指定来源的手动压缩包可能无法自动定位；不会扫描整盘猜测删除。

该版本仍为本机管理预览版。ARM64 发行包是交叉编译结果；真实 frp TCP 联调、Windows 原生生命周期及发布情况以此版本的 Actions 结果为准。
