## 基本功能

- frp 客户端和服务端代码编入工作台，可以在本机创建实例、配置和启停规则，不再需要为运行时单独下载 frpc 或 frps。支持配置 TCP、UDP、HTTP、HTTPS、TCPMUX、STCP、XTCP、SUDP 及相应的访问端；实际协议互通仍需验收。
- 工作台提供实例状态、运行记录、代理注册状态和本地目标检测。保存只更新草稿，运行中的实例需重启后应用；实例运行或代理已注册不代表公网和目标服务可达。
- 支持本地账户和实例权限、配置快照与备份、TOML 导入和规则导出。远程节点查看和控制需要分别授权，并由管理员准备可信的 HTTPS 入口。

## 主题

随包提供可离线使用的狂三经典灵装主题，界面支持深浅配色和手机尺寸。管理员可另外从 GitHub 下载白裙晴空、魔术侦探书房和紫色魔女月夜主题；其他本地账户可选择已安装的主题。

## 计划提供的安装包

- Windows：一个 Setup 安装包，支持 x64 和 ARM64。
- Linux：amd64、arm64、armhf、riscv64 的 DEB；x86_64、aarch64 的 RPM。
- 其他 Linux 设备：ARM、ARM 硬浮点、RISC-V 64、LoongArch 64、MIPS 大小端 32/64 位便携压缩包。

上述是构建目标，是否提供以实际发布附件为准；交叉编译成功不代表目标设备、发行版或转发协议已经验收。macOS 当前工作流只检查源码构建，没有生成安装包。Windows 安装包尚未配置 Authenticode 签名，Linux 也没有在线 APT/YUM 软件源或仓库 GPG 签名。

## 首次登录与升级

管理界面只监听本机回环地址。新数据目录的管理员登录不填用户名、密码留空；登录后可设置密码。已有数据目录如果尚未设置主密码，初始密码为原本机管理令牌；已有本地账户继续使用原密码。请保护该令牌及备份，不要分享给他人。

升级前先停止工作台和连接，并备份完整的数据目录及密钥。Windows 旧版安装或重装中断可能留下维护标记，旧卸载器不会主动停止工作台。重新操作前请确认旧安装器、维护进程及所有账户的工作台均已退出，并保护原数据；不要删除未知标记、覆盖原目录或用旧卸载器清理数据。0.7 安装器的中断恢复及与新版本交接尚未完成验收。安装目录、备份和迁移方式见 [安装说明](https://github.com/Presikid/KurumiFrp/blob/main/docs/INSTALL.md)。

Linux 便携版更新时应解压到新的空目录，再通过 `--data` 指向原数据目录；不要直接覆盖旧目录。请先核对对应架构及安装方式。
