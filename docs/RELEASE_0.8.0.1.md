## Windows 卸载修复

- 卸载前自动停止各 Windows 账户的 KurumiFRP 工作台和连接，再移除程序文件与快捷方式；账户数据和重新安装所需的记录会保留。
- 如果其他进程仍占用主程序，Windows 可在重启时自动删除该文件。不能安全停止工作台时，卸载会在移除程序文件前中止。
- 覆盖安装沿用已有卸载记录，避免每次升级都新建一套卸载记录。

0.8.0.0 已安装的卸载器不会自动改变，请先覆盖安装本版本，再使用系统的应用卸载入口。0.8.0.0 如已卸载，重新安装时选择原安装目录以接回保留的数据。

此修复尚未经过实际 Windows 安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他功能和限制见 [0.8.0.0 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.0)。
