## Bug 修复

- 防止跨设备导入使本机已有 FRP 凭据不可读并影响后续受管登录。若导入会更换数据加密信息且本机仍有 FRP 凭据登记，导入会先停止并提示管理员处理；数据加密信息相同的导入不受该限制。
- 恢复历史配置前先完成部分确定性校验，减少失败操作提前撤销账户授权的情况；若后续保存失败，会提示核对配置和相关授权。
- 修正规则切换协议后搜索仍匹配旧端口、域名或目标占位字段的问题，保留当前有效字段和 Visitor 负端口搜索。

## 已知限制

跨设备导入保护当前要求先停用本机现有的 FRP 凭据登记，不会自动迁移这些凭据。磁盘写入等后续失败仍可能发生在授权撤销之后。

Windows 启动期间旧管理地址可能误连其他本地服务；异常中断后遗留的运行锁或维护标记仍可能阻止启动、更新或卸载。通过工作台启动的安装器结束后，专用更新暂存目录可能残留安装包。

Linux 更新服务已经运行时，新请求仍可能因监听时序而未被处理；RPM 升级仍可能改变原本禁用或停止的服务状态。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复见 [0.8.0.9 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.9)。
