## Bug 修复

- 修复部分总览界面将受限账户不可查看的配置、规则或事件误显示为零的问题；已有查看权限的零值仍正常显示。
- 工作台关闭清理未完成时，通过标准 Windows 快捷方式启动时会显示更明确的中文错误，同时保留运行锁和原始错误信息。

## 已知限制

部分界面在并发刷新时仍可能关闭正在编辑的窗口。跨设备导入若更换数据加密信息，当前保护要求先停用本机现有的 FRP 凭据登记，不会自动迁移这些凭据；磁盘写入等后续失败仍可能发生在授权撤销之后。

Windows 启动期间旧管理地址可能误连其他本地服务；异常中断后遗留的运行锁或维护标记仍可能阻止启动、更新或卸载。通过工作台启动的安装器结束后，专用更新暂存目录可能残留安装包。

Linux 更新服务已经运行时，新请求仍可能因监听时序而未被处理；RPM 升级仍可能改变原本禁用或停止的服务状态。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复见 [0.8.0.10 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.10)。
