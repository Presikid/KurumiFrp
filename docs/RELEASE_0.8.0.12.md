## Bug 修复

- 修复普通账户在总览中没有可查看实例时仍被提示创建实例的问题，并标明运行中和待应用统计仅覆盖可查看实例。
- 修复实例复制、计划、批量规则操作及实例控制等操作在会话切换后，旧结果可能刷新或提示到新会话的问题；实例启停结果未确认时仍保留核对记录。
- 修复批量停止期间旧操作可能改动新对话框的问题，并在批量检测过程中检查页面和草稿是否变化。

已发出的请求即使切换会话也可能继续执行；请在原账户核对操作结果。

## 更正

0.8.0.11 发布说明中的受限账户总览显示修复，只作用于默认界面未加载的旧代码，不影响默认工作台。本版单独修正了上述默认总览提示和统计范围。

## 已知限制

Windows 安装或卸载在特定阶段异常中断后，维护标记可能残留并阻止启动或重装；正常卸载会保留账户数据及重装所需记录。Windows 启动期间旧管理地址仍可能误连其他本地服务，异常中断也可能遗留运行锁；通过工作台启动的安装器结束后，更新暂存目录可能残留安装包。

Linux 更新服务已运行时，新请求仍可能因监听时序未被处理；RPM 升级仍可能改变原本禁用或停止的服务状态。部分界面并发刷新时仍可能关闭正在编辑的窗口。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。
