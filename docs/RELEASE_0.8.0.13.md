## Bug 修复

- 自动选择管理地址后，如果工作台在取得运行锁前发生竞争，重复打开操作不再连接仅通过空闲探测得到的端口，而会提示稍后重试。
- 批量复制规则的确认框返回后重新检查页面和会话，避免将旧页面的选择提交到已变化的会话；刷新完成后也不会向新会话显示旧结果。

## 已知限制

上述地址修复只覆盖空闲端口探测后发生锁竞争的情况；此前保存的管理地址仍不能证明对应当前工作台，启动或停止时仍存在误连风险。

Windows 安装或卸载在特定阶段异常中断后，维护标记可能残留并阻止启动或重装；正常卸载保留账户数据及重装所需记录。异常中断也可能遗留运行锁；通过工作台启动的安装器结束后，更新暂存目录可能残留安装包。

Linux 更新服务已运行时，新请求仍可能因监听时序未被处理；RPM 升级仍可能改变原本禁用或停止的服务状态。部分界面并发刷新时仍可能关闭正在编辑的窗口。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复及 0.8.0.11 说明更正见 [0.8.0.12 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.12)。
