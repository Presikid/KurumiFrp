## Bug 修复

- TOML 导入在配置或预览发生冲突、服务器明确拒绝时，显示实际原因并解除错误的“结果未确认”阻塞；无法确认的错误仍保留核对提示。
- 节点授权弹窗在会话或账户权限变化时清空并关闭，旧请求结果不会显示到新的身份；普通同身份页面刷新会保留弹窗。
- 节点授权生成遇到超时或服务端错误时明确提示结果可能未确认，管理员关闭弹窗后仍可在当前标签页的节点页面查看核对提示。

## 已知限制

节点授权的核对提示仅保存在当前标签页内存中，整页重载后会丢失；会话过期时有可能保守地提示需要核对。

Windows 安装或卸载在特定阶段异常中断后，维护标记可能残留并阻止启动或重装；正常卸载保留账户数据及重装所需记录。此前保存的管理地址仍不能证明对应当前工作台，启动或停止时仍存在误连风险；异常中断也可能遗留运行锁。通过工作台启动的安装器结束后，更新暂存目录可能残留安装包。

Linux 更新服务已运行时，新请求仍可能因监听时序未被处理；RPM 升级仍可能改变原本禁用或停止的服务状态。部分界面并发刷新时仍可能关闭正在编辑的窗口。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复见 [0.8.0.13 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.13)。
