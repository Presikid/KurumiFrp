## Bug 修复

- Windows 卸载时，如果安装说明或程序图标无法立即删除，卸载器会像处理主程序一样尝试安排重启后删除，避免部分文件占用情况需要手动清理。Windows 可能要求重启；排队或重启后的删除仍可能失败。
- 移除了主分支残留的自动化测试源码。

## 已知限制

这次卸载修复只覆盖已安装文件无法立即删除时的处理，不保证解决权限、注册表、历史卸载记录或其他失败。安装或卸载异常中断后，维护标记仍可能残留并阻止启动或重装；账户数据及重装记录仍会保留。

此前保存的管理地址仍不能证明对应当前工作台，启动或停止时仍存在误连风险；异常中断也可能遗留运行锁。通过工作台启动的安装器结束后，更新暂存目录可能残留安装包。

Linux 更新服务运行时，新请求仍可能因监听时序未被处理；更新请求在后台准备阶段中断时也可能丢失。RPM 升级仍可能改变原本禁用或停止的服务状态。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复见 [0.8.0.14 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.14)。
