## Bug 修复

- 修复内嵌 frps 启动时部分监听失败只显示笼统错误、实例日志缺少原因的问题。主 TCP、TCPMux、独立 HTTP/HTTPS 及 KCP 的监听错误会写入对应实例日志，便于排查端口占用和地址问题。
- QUIC 监听初始化失败会写入概括提示，不记录可能包含 TLS 或配置细节的原始错误。实例日志仍受账户日志权限控制，并使用现有的配置秘密脱敏；日志队列繁忙时可能丢弃记录。

## 已知限制

Windows 安装或卸载异常中断后，维护标记仍可能残留并阻止启动或重装。此前保存的管理地址仍不能证明对应当前工作台，启动或停止时仍存在误连风险；异常中断也可能遗留运行锁。通过工作台启动的安装器结束后，更新暂存目录可能残留安装包。

Linux 更新服务运行时，新请求仍可能因监听时序未被处理；更新请求在后台准备阶段中断时也可能丢失。RPM 升级仍可能改变原本禁用或停止的服务状态。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。卸载相关修复和限制见 [0.8.0.15 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.15)。
