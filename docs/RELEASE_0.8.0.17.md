## Bug 修复

- 修复内嵌 frpc 的代理注册失败后进入重试时，界面仍把上一轮错误显示成当前“注册失败”的问题。等待新结果时显示“注册中”；FRP 的原始状态、重试间隔和已有日志不变，旧远端地址仍按原规则过滤。
- “注册中”只表示核心正在等待注册结果，不保证请求已送达或连接可用；一直收不到响应时可能持续显示。

## 已知限制

Windows 安装或卸载异常中断后，维护标记仍可能残留并阻止启动或重装。此前保存的管理地址仍不能证明对应当前工作台，启动或停止时仍存在误连风险；异常中断也可能遗留运行锁。通过工作台启动的安装器结束后，更新暂存目录可能残留安装包。

Linux 更新服务运行时，新请求仍可能因监听时序未被处理；更新请求在后台准备阶段中断时也可能丢失。RPM 升级仍可能改变原本禁用或停止的服务状态。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。监听错误日志的修复见 [0.8.0.16 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.16)。
