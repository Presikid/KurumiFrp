## Bug 修复

- 实例启动、停止或重启已受理后，在状态刷新完成前继续阻止重复提交；刷新失败、会话或权限变化时保留核对提示。
- 批量停止的成功项在统一刷新前保持保护；中断或刷新失败时保留对应记录。错误详情不会在身份权限变化后继续向新身份显示。
- 对页面显示为运行中的实例执行停止或重启时，复核页面所显示的运行代次，避免旧页面操作到新代次；启动中或停止中的停止操作保持原有行为。

## 已知限制

实例操作记录使用浏览器本地存储；跨标签页的读取和删除不是原子操作，严格并发时仍可能发生记录竞争。浏览器存储不可用时，提示只保存在当前页面内。

Windows 安装或卸载异常中断后，维护标记仍可能残留并阻止启动或重装。此前保存的管理地址仍不能证明对应当前工作台，启动或停止时仍存在误连风险；异常中断也可能遗留运行锁。通过工作台启动的安装器结束后，更新暂存目录可能残留安装包。

Linux 更新服务运行时，新请求仍可能因监听时序未被处理；更新请求在后台准备阶段中断时也可能丢失。RPM 升级仍可能改变原本禁用或停止的服务状态。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。此前注册状态的修复见 [0.8.0.17 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.17)。
