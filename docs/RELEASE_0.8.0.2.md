## 管理员空密码修复

- 数据目录没有管理员密码文件时，初始化为空密码，包括已经启动过但尚未设置主密码的数据目录。登录时管理员用户名和密码均留空；登录后可以设置密码。
- 已有管理员密码文件及本地账户密码保留；不再兼容 0.8 之前的初始认证方式。
- 包含 0.8.0.1 的 Windows 卸载流程修正；升级时请使用原安装目录。

此次发布基于源码修改和远程打包，尚未完成实际登录、安装、升级及卸载验收。Windows 安装包未签名；macOS 仅编译源码，没有安装包。更多功能与限制见 [0.8.0.0 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.0)。
