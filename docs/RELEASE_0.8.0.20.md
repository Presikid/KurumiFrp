## 工作台访问

- 工作台使用一个全局访问密码，不需要用户名；尚未设置密码的数据目录初始密码为空，已有主密码保持不变。
- 移除本地账户、分组、用户配额和单点登录功能及其相关接口、页面和主要后台代码；保留全局密码修改、登录记录、本机维护通道和独立节点授权。
- 清理不再使用的旧工作台脚本。狂三主题、普通 frp 连接认证、规则、定时计划和流量功能继续保留。

## 旧配置处理

旧版受管账户认证的 frps 配置仍可读取，但不能以该模式校验、启动、重启或复制。请在实例编辑器中明确转换为普通 frp 共享令牌，输入并确认令牌后保存；客户端也需同步核对令牌和 TCP 多路复用设置。历史快照和配置备份恢复会按所选内容还原认证配置，请核对后使用。

旧版账户资料不会自动删除，普通配置操作不再读取或改写它。若导入或恢复备份需要更换数据密钥，而旧版账户文件仍存在或无法确认不存在，程序会保守拒绝；即使文件为空也会触发保护。完整数据目录备份和后续处理见[访问与旧数据说明](https://github.com/Presikid/KurumiFrp/blob/main/docs/PERMISSIONS_0.8.md)。降级到旧版前需另行核对保留的旧授权。

## 已知限制

Windows 安装或卸载异常中断仍可能遗留维护标记；此前“部分组件未卸载”提示的全部原因尚未确认。Linux 更新请求仍可能在准备或监听期间遗漏，RPM 升级也可能改变服务状态；其他限制见 [0.8.0.19 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.19)。

本次通过 GitHub Actions 构建和打包，尚未完成实际浏览器、协议、安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。
