## Bug 修复

- 当主题下载等操作仍在使用工作台时，修改控制面板密码不再无限等待这些操作结束。若暂时无法安全提交，界面会提示本次修改未提交，请等当前操作结束后重试。
- 退出登录也采用相同的处理：已有操作尚未结束时，明确提示本次未退出，请稍后重试。
- 包含 [0.8.0.22](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.22) 的启动与 Linux 安装修复。工作台仍为无账户、单密码控制面板；新数据目录的默认密码为空，已有密码保留。

## 已知限制

工作台持续繁忙时可能需要多次重试。密码计算或磁盘操作过慢、连接中断等情况下，结果仍可能无法确认；界面会要求重新登录核对，不应把网络错误视为密码肯定未变。

自定义回环地址的自动启动与 Linux 服务状态保留限制见 [0.8.0.22 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.22)。Linux 更新请求在准备或监听期间仍可能遗漏。Windows 安装或卸载异常中断仍可能遗留维护标记；此前“部分组件未卸载”提示的全部原因尚未确认。

本次通过 GitHub Actions 构建和打包，尚未完成真实 systemd 安装升级、浏览器、协议和 Windows 卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。
