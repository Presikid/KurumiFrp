## Bug 修复

- Windows 安装程序为它登记的程序文件启用卸载时移除只读属性，避免这些文件仅因只读而无法删除并触发“部分组件未完全卸载”提示；文件仍被占用时保留原有的重启后删除处理。此修复作用于安装本版时生成的文件记录，不递归修改工作台数据。
- 修正安装与卸载提示中容易被理解为软件账户的表述，明确区分 Windows 用户和工作台数据。
- 旧 frps 配置预览不再声称已停用的账户认证仍可使用，提示在实例编辑器中转换为共享令牌；计划和日志提示也不再要求联系软件“管理员”。
- 包含 [0.8.0.23](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.23) 的密码修改和退出修复。控制面板无账户和用户名，新数据目录默认空密码，已有密码保留。

## 已知限制

只读文件只是卸载通用提示的一种可能原因；权限错误、注册表或其他安装记录的问题仍可能导致卸载失败。旧版已生成的卸载记录不会自动获得本版标志。Windows 安装或卸载异常中断仍可能遗留维护标记；使用 IPv6 回环地址运行的工作台目前无法通过卸载维护流程自动停止。已保存计划中的旧暂停文字不会被自动改写。

Linux 更新请求及服务状态的已知限制见 [0.8.0.22 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.22)。

本次通过 GitHub Actions 构建和打包，尚未完成真实 systemd 安装升级、浏览器、协议和 Windows 卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。
