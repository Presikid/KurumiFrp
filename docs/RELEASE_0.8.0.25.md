## 修复

- 修复跨标签登录后退出时，登录页可能保留旧的“密码不正确”提示；操作结果未确认的提示在重复身份通知时仍会保留。
- 修正 Linux 便携包随附说明和容器指南中有关用户名、初始密码的错误。控制面板不需要用户名；数据目录没有密码文件时初始密码为空，已有密码保持不变。
- 更新定时计划、日志和安装指南，使其与单密码访问、当前日志历史及已发布安装包一致；Windows 更新提示明确区分系统账户与控制面板登录。
- 包含 [0.8.0.24](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.24) 的 Windows 卸载修复。

## 已知限制

Windows 安装或卸载异常中断后仍可能遗留维护标记；使用 IPv6 回环地址运行的工作台暂不能由维护流程自动停止。Linux 更新请求在特定时序下仍可能遗漏。更多卸载和服务状态限制见 [0.8.0.24 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.24)。

本次通过 GitHub Actions 构建和打包，未在本机运行 KurumiFRP 或测试，也未完成真实安装、协议、浏览器或异常恢复验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。
