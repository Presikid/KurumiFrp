## Bug 修复

- 修复 Windows 安装程序在工作台初始化失败后仍可能显示安装成功的问题。完成页会提示初始化未完成；在安装器原本会返回成功码时，改为返回非零退出码。
- 初始化发生在程序文件和卸载记录写入后；失败提示表示安装未完整完成，不代表已回滚。原有数据及安装状态需核对。
- 包含 [0.8.0.25](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.25) 的登录提示和无账户使用说明修复。控制面板只使用一个密码，无需用户名。

## 已知限制

Inno Setup 已确定的其他非零退出码（例如调用方指定的重启退出码）仍按其原有规则返回。工作台内的 Windows 更新器异步启动安装程序，不等待或读取其退出码；请以安装程序的提示和重新打开后的版本为准。未抑制消息框的静默安装遇到错误时仍可能等待确认。

Windows 安装或卸载异常中断后仍可能遗留维护标记；使用 IPv6 回环地址运行的工作台暂不能由维护流程自动停止。Linux 更新请求在特定时序下仍可能遗漏。日志历史轮转时若旧文件已移除但重命名失败，较早历史可能丢失；这些问题仍待处理。

本次通过 GitHub Actions 构建和打包，未在本机运行 KurumiFRP 或测试，也未完成真实安装、协议、浏览器或异常恢复验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。
