## Bug 修复

- 修正实例卡片和 TOML 导入预览的 IPv6 地址显示；Unix 套接字、SOCKS5 和仅接收回退连接的 Visitor 也显示各自正确的目标说明。该改动不改变保存的配置。
- 修复在其他标签页产生更新待核对记录后，重新进入更新页可能看不到提示的问题。浏览器存储读取失败时保留已有本页记录；损坏的记录需要先核对。用户确认解除后，如浏览器未能删除持久记录，会提示该记录可能再次出现。
- 包含 [0.8.0.26](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.26) 的 Windows 安装初始化失败提示修复。控制面板无账户和用户名，使用一个密码。

## 已知限制

更新提示的跨标签读写仍不保证原子性；首次加载时若浏览器存储完全不可读，无法判断其中是否有旧记录。Linux 更新请求在特定时序下仍可能遗漏。

Windows 安装或卸载异常中断后仍可能遗留维护标记；使用 IPv6 回环地址运行的工作台暂不能由维护流程自动停止。日志历史轮转时若旧文件已移除但重命名失败，较早历史可能丢失。更多安装与卸载限制见 [0.8.0.26 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.26)。

本次通过 GitHub Actions 构建和打包，未在本机运行 KurumiFRP 或测试，也未完成真实安装、协议、浏览器或异常恢复验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。
