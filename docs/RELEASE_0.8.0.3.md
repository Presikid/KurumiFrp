## 本次修复

- 替换默认登录页面的桌面和手机插画，使用素材库中的狂三工作台形象。
- 修复账户文件写入状态不确定时，旧账户会话仍可能继续使用旧权限的问题；账户管理页面会提示需要核对的状态。修正账户在密码计算期间变化时可能误记登录失败的问题。
- 改善可选主题在慢速网络下的下载，并减少重复裁切的图片；主题选择界面可预览已安装的主题。
- 修复 Linux 更新的下载期限可能中断正在进行的软件包安装、Windows 更新取消授权后留下临时下载的问题。
- 修复部分发行版元数据无法确认时影响其他可用版本显示的问题。
- 管理器锁文件写入或关闭失败时停止启动；受管实例停止未确认时记录提示。

## 已知限制

Windows 工作台或维护程序异常中断后，遗留的运行锁或维护标记仍可能阻止启动、更新或卸载。账户文件写入异常后，若受管 FRP 实例无法确认停止，已有转发可能继续运行；请确认工作台已完全停止后再启动并核对账户配置。这两项仍在修复中。

本次通过 GitHub Actions 打包，尚未完成实际登录、安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他功能与限制见 [0.8.0.0 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.0)。
