## Bug 修复

- 修复卸载或升级恰逢工作台启动时，管理服务尚未就绪就立即报告停止失败的问题。对状态文件尚未出现或本机连接明确被拒绝的情况，在原有时限内等待并重试；其他错误仍停止操作。
- 修复受管 FRP 服务关闭时，连接清理可能被共享资源关闭过程阻塞的问题。现在会提前请求清理受管连接，并等待清理结果，未确认时不会报告安全关闭。

## 已知限制

Windows 工作台或维护程序异常中断后，遗留的运行锁或维护标记仍可能阻止启动、更新或卸载。若底层连接清理无法完成，受管转发的关闭结果仍可能无法确认。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复见 [0.8.0.3 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.3)。
