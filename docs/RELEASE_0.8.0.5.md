## Bug 修复

- 修复 GitHub API 限流时，个别旧版本的附件查询超时可能导致整个更新列表不可用的问题；已确认的结果可以保留，尚未确认的安装包会明确标注。
- 修复安装指定版本时受发行列表前 100 项限制的问题，并避免等待无关版本的附件查询。安装包仍须通过官方地址、大小和 SHA-256 校验。
- 修复刷新后发布状态变为未确认的版本仍可能被自动选中的问题。
- 修复更新通知因限频或通知队列已满而可能永久漏发的问题；后续版本检查会再次尝试入队。

## 已知限制

Windows 工作台或维护程序异常中断后，遗留的运行锁或维护标记仍可能阻止启动、更新或卸载。受管连接底层清理未完成时，停止结果仍可能无法确认。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复见 [0.8.0.4 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.4)。
