## Bug 修复

- 修复配置页面切换登录账户后，上一会话的异步操作可能在新会话显示结果或触发旧页面重读的问题。
- 限制安装与卸载维护程序读取本地状态文件的大小，避免异常大文件导致维护进程内存耗尽。
- 调整发布任务排队方式，避免较早的工作流事件取消后续版本的打包发布。

## 已知限制

Linux 系统安装连续提交更新请求时仍可能发生请求丢失；Windows 启动期间旧管理地址可能被误用。Windows 工作台或维护程序异常中断后，遗留的运行锁或维护标记仍可能阻止启动、更新或卸载。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复见 [0.8.0.5 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.5)。
