## Bug 修复

- 防止 Linux 系统安装中尚未消费的更新请求被后续请求覆盖；重复提交会在更新状态中报告已有待处理请求。
- 修复 TCPMUX 规则未显示路由用户名、按该用户名搜索不到规则的问题。

## 已知限制

Linux 更新服务已经运行时，新请求仍可能因系统监听时序而未被处理；本次修复不涵盖这一情况。极少数同时不支持所需原子操作和硬链接的文件系统无法提交系统更新请求。

Windows 启动期间旧管理地址可能被误用；工作台或维护程序异常中断后，遗留的运行锁或维护标记仍可能阻止启动、更新或卸载。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复见 [0.8.0.6 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.6)。
