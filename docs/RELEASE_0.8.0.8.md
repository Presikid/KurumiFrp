## Bug 修复

- 修复 RPM 包升级可能将原本已启用的工作台服务重置为禁用的问题。
- 修复实例页面在定时计划优先时仍声称会自动恢复的问题。
- 修复部分界面将未查询或草稿待应用时的代理注册状态误显示为零的问题。

## 已知限制

RPM 升级仍可能改变原本禁用或停止的服务状态。Linux 更新服务已经运行时，新请求仍可能因监听时序而未被处理。

Windows 启动期间旧管理地址可能误连其他本地服务；异常中断后遗留的运行锁或维护标记仍可能阻止启动、更新或卸载。通过工作台启动的安装器结束后，专用更新暂存目录可能残留安装包。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复见 [0.8.0.7 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.7)。
