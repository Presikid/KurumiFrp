## Bug 修复

- 修复工作台关闭清理未完成时进程仍可能报告成功的问题；原有错误与关闭错误会保留，未确认关闭时仍保留运行锁。
- 卸载确认中说明保留数据的重新使用方式：重装时选择原安装目录，之后使用原 Windows 账户。

## 已知限制

Windows 启动期间旧管理地址可能误连其他本地服务；异常中断后遗留的运行锁或维护标记仍可能阻止启动、更新或卸载。通过工作台启动的安装器结束后，专用更新暂存目录可能残留安装包。

Linux 更新服务已经运行时，新请求仍可能因监听时序而未被处理；RPM 升级仍可能改变原本禁用或停止的服务状态。

本次通过 GitHub Actions 打包，尚未完成实际安装、升级和卸载验收。Windows 安装包未签名；macOS 仅编译源码，不提供安装包。其他修复见 [0.8.0.8 发布说明](https://github.com/Presikid/KurumiFrp/releases/tag/v0.8.0.8)。
