# 远程节点状态与控制

此功能可按需查看另一个工作台的实例名称、类型和进程状态。目标管理员可另行开启远程启动、停止和重启，默认关闭；只读授权不能操作实例。两种授权独立，分别只有一个共享值，重新生成或撤销会影响使用对应授权的所有控制端。目标的共享控制授权可操作该目标的全部实例；进程运行不代表代理已注册或业务可达。

目标管理员还可在已有只读授权的前提下单独开启流量共享，默认关闭。开启后，所有持有该只读授权的控制端都可按需读取目标上运行中实例的当前收发计数；关闭共享会等待此前获准的摘要发送完成或失败，已经发送的数据无法撤回；撤销只读授权时同时关闭流量共享。计数仅属于当前运行代次，不可用于计费或配额：客户端为业务载荷，服务端在转发边界统计，部分包含协议开销且不包括绕过服务端的 P2P 流量。无可用数据时不显示数字，不代表零流量。

开启流量共享会在节点摘要加入可选字段；较早版本若严格拒绝新字段，可能无法读取开启共享的目标。应先升级控制端，或关闭流量共享再连接旧控制端。

## 连接前准备

1. 在目标工作台的「节点管理」中选择「生成 / 更换授权」。新授权只显示一次；原授权立即失效。通过安全渠道把它交给获准的控制端。显示前断线或关闭页面时，新授权可能已经生效而无法找回，应重新生成并更新所有控制端。
2. 管理员在目标设备配置可信 HTTPS 反向代理，转发 `GET /api/node/summary`；仅当需要远程启停时才额外转发 `POST /api/node/control`。其他路径应拒绝；上游 `Host` 改成工作台实际的回环地址和端口。工作台本身不会对公网监听，也不会自动配置反向代理、防火墙、证书或 DNS。
3. HTTPS 地址的证书必须被控制端运行 KurumiFRP 的操作系统信任且匹配该地址。仅连接可信的代理，代理可看到授权和所返回的状态；保护代理配置、访问日志和网络边界。
4. 如需远程控制，目标管理员还须单独生成控制授权，经安全渠道交给获准的控制端。控制授权与只读授权不同，掌握者能启动、停止或重启目标的所有实例；移除旧版本的本机账户不会自动撤销该独立授权。
5. 在控制端添加节点，填写 HTTPS 来源地址（不含路径、查询、片段或用户信息）和只读授权；需要启停时再填写控制授权。保存后点击「核对地址」，确认列出的 IP 属于目标，再点击「检查状态」。更改 HTTPS 地址时须重新填写只读授权，原控制授权会被清除，且须重新确认解析地址。

例如，在具有有效证书和对应名称解析的 Nginx 中，可按实际端口与本机监听地址调整以下结构。证书文件和服务配置由目标管理员自行提供；不要把整个工作台或登录接口暴露出去。

```nginx
server {
    listen 443 ssl;
    server_name node.example.com;
    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/private-key.pem;

    location = /api/node/summary {
        limit_except GET { deny all; }
        proxy_set_header Host 127.0.0.1:9000;
        proxy_pass http://127.0.0.1:9000;
    }
    # 仅在明确启用远程启停时加入此精确路径。
    location = /api/node/control {
        limit_except POST { deny all; }
        proxy_set_header Host 127.0.0.1:9000;
        proxy_read_timeout 45s;
        proxy_pass http://127.0.0.1:9000;
    }
    location / { return 404; }
}
```

如果目标工作台使用自动端口，需要根据实际监听端口更新示例中的 `9000`。应另外限制可访问代理的网络来源，并确认代理不会把 Authorization 请求头写入日志。控制端只允许经 HTTPS 检查，使用正常证书校验，不使用系统代理、不跟随重定向；不支持自定义 CA 文件或关闭校验。首次检查前必须确认域名当前解析出的全部 IP；若解析结果的 IP 集合发生变化，检查停止且不发送授权，需要再次核对确认。实际连接直接拨打已确认 IP，TLS 仍验证原 HTTPS 地址的主机名，避免解析后再次查找时被替换。允许内网和回环地址；最多确认 16 个不同 IP，空结果或过多地址会被拒绝。

服务商使用轮换或动态 DNS 时，合法变更也需要重新确认，这是防止地址变化被悄悄接受的取舍；顺序变化和重复记录不影响比较，只监控最终 IP 集合，不监控未改变最终地址的 CNAME 或 TTL 变化。确认前请独立核对 IP 归属；已确认 IP 上的服务如果被替换，仍依靠 HTTPS 证书校验识别，不保证该服务本身可信。

连接超时、拒绝授权和不受信任证书不会被显示成在线。状态检查和操作预览最多等待 5 秒；启动或停止的控制端最多等待 40 秒。管理员可在节点页面手动检查，也可临时开启页面自动检查：只在页面可见且没有节点操作或对话框时，依次检查已确认地址的节点，每轮结束后等待 30 秒。离开页面、退出登录或点击停止会结束后续页面检查；正在进行的检查可能先完成，该选择不会保存。

管理员还可为单个已确认地址的节点开启后台检查。设置保存在本机；工作台运行期间约每分钟检查，关闭页面后仍继续，重启后自动恢复。结果仅保留在本次进程内，列表显示最近结果和时间；页面可见时约每 30 秒读取结果，不会重新创建卡片或主动检查目标。管理员总览另显示本次工作台进程最近一次后台检查成功的时间；失败不会覆盖这个时间，手动检查不计入。尚无成功观测时明确显示未知，工作台重启、节点设置变化或关闭后台检查后记录清除；关闭前已开始的检查若在重新开启后结束，仍可能重新记录结果。进入总览和点击“刷新观测”只读取控制端本机保存的观测，不会触发远端检查。一次失败先标记待复查，连续两次失败才标记为未确认可用，并向开启状态通知的目标发送节点事件，恢复后再发送恢复事件。地址解析发生变化时不会发送授权，需重新核对。检查与操作共用最多 4 个并发槽，繁忙时会跳过本次，不会因此判定失败。检查结果只是控制端拉取的观察快照，不是节点主动上报，也不代表业务可达；最多保存 32 个远程节点。

操作前会向目标获取该实例的最新状态和版本，显示名称与状态并要求用户确认。目标在同一锁内核对配置修订、进程运行代次、目标工作台运行代次和操作占用后预约执行；状态或配置变化时拒绝。实例的操作通过实例、动作和占用检查后，即使渲染、核心解析、执行失败或取消，也会使此前的预览失效。启动沿用本机配置验证，停止沿用本机进程停止流程，既有实例状态 Webhook 照常触发。重启仅适用于运行中的实例，会先检查目标当前草稿，再停止旧实例并应用草稿；若停止后启动失败、配置发生变化或请求取消，实例可能保持停止。较早的目标工作台可能不支持重启，操作未获确认时应先核对目标状态。控制共享授权没有逐控制端身份和专门的操作归属审计。

## 撤销与数据保护

在目标工作台分别撤销只读和控制授权才能终止相应的后续访问；从控制端删除节点或清除控制授权只影响本机保存，不能代替目标撤销。控制请求在目标已验证并预约后，即使控制授权随后撤销也可能继续完成；撤销不会回滚已发生的动作。撤销或轮换会等待已获准的摘要写入完成或失败，然后才发布新授权状态；每个摘要有两秒写入期限，其他配置锁或存储操作仍可能增加等待时间。已交给系统网络栈或反向代理缓冲的响应仍可能在撤销后到达，无法撤回。目标上已经开始读取的检查也可能完成。生成或保存结果在断线时不确定，请刷新并核对，再决定是否重试；生成授权的不确定结果需要重新生成。

目标仅保存两种授权各自的 SHA-256 校验值。控制端使用本机数据密钥分别加密保存授权，绝不通过节点列表接口返回它们；此加密依赖本机文件和操作系统账户权限，不能防止同一系统账户或管理员读取本机数据。节点设置和授权不进入配置导出、快照或加密备份。导入配置和恢复备份保留本机节点及本机两种授权，并在数据密钥更换时重加密两种控制端授权；其他设备恢复备份后需要分别重新添加节点和授权。Webhook 设置继续保留。

节点设置添加到格式 4 单文件时，旧程序若不能识别 `nodes` 字段应拒绝读取，不能忽略字段后写回；不要以旧程序覆盖新数据。缺损或无法解密的本机节点设置会导致启动拒绝并保留原文件，需先保护原件再排查。

## 接口与授权边界

旧版按本地账户分配远程实例权限的功能已移除。目标工作台的只读授权和控制授权仍是独立凭据；需要终止相应访问时，请在目标工作台分别撤销或更换。

`GET /api/node/summary` 只接受目标生成的只读 Bearer 授权，返回协议版本、工作台版本以及实例 ID、名称、类型、进程状态和非密钥的实例身份标识 `binding`；显式开启流量共享后还可能返回当前运行代次的总收发字节和采样时间，不返回令牌、规则、配置、日志或错误详情。`POST /api/node/control` 只接受独立控制授权，允许预览一个指定实例以及携带该实例版本和明确确认标记的启动、停止或重启；两者均不能使用本机登录会话或本机访问令牌替代授权。旧目标若不提供 `binding`，管理员仍可读取状态，但新界面不能安全操作该实例；不认识新字段的旧控制端可能拒绝读取新版目标。

协议 1 未定义启动中或停止中；有实例处于过渡状态时，目标摘要暂返回 HTTP 503，该实例的控制预览暂返回 HTTP 409，请稍后重试。启动请求成功只表示目标已受理；内置实例需要等待引擎就绪后才会显示运行中，客户端就绪不代表认证或链路连通。

主动上报使用独立的会话能力协商。发送端和接收端均支持时，报告可以如实包含“启动中”和“停止中”，这些状态不附带流量；旧接收端或代理移除能力响应头时，过渡期间仍暂缓发送整份报告。更新接收端后，发送端需建立新会话才能发现新增能力。报告是某一时刻的快照，不代表业务可达。

管理员打开“主动上报”页面时，接收列表在页面可见且没有编辑、凭据展示或其他操作时，约每 30 秒读取一次本机已接收的节点快照；也可手动刷新。隐藏或离开页面、退出登录会停止后续自动读取。正在查看展开的摘要、选择文字、列表项保持焦点或进行相关操作时，自动读取会暂缓；关闭摘要、移出焦点并恢复空闲后再继续。此读取只访问本机管理接口，不向上报设备发送请求。列表显示本机最近读取时间；约 90 秒未更新会标记为过期，读取失败时会提示并停用列表操作。读取时间使用浏览器所在设备的时钟，和节点报告的最近接收时间是两个不同时间；即使列表刚刷新，报告也可能延迟，不能证明节点或业务当前可达。

`GET /api/nodes`、`POST /api/nodes`、`POST /api/nodes/check`、`POST /api/nodes/control`、`POST /api/nodes/resolve` 和 `POST /api/nodes/confirm` 是本机管理接口，适用现有 Host、Origin 和本机身份校验。列表返回不含明文授权的记录快照标识；解析和检查先验证标识，返回前再次验证，地址确认还会重查 DNS 和配置修订号。网络检查不持有配置锁，实际连接只拨打已确认地址。节点设置变更不会触发实例配置变更 Webhook，也不操作目标配置。

操作结果在断线或超时时可能未知，页面不自动重试。提交前每次操作会在浏览器本地存储中单独记录节点 ID、实例 ID 和动作，不保存名称或授权；未确认记录会在后续打开页面时提示。无法写入本地存储时不能提交操作。请独立核对目标和网络请求状态后，再点击「核对后解除」并确认；解除记录本身不会读取目标，也不能取消可能仍在执行的操作。清除站点数据、浏览器不保留数据或操作过程中存储故障仍可能丢失记录，不能仅凭提示消失认定结果；关闭页面或断线也无法保证操作取消。

目标摘要、控制预览和授权变更先取得各自的节点授权门闩、再取得应用锁，不同时持有两个节点门闩。状态复制后释放应用锁，在受限写入期限内刷新只读响应，再释放门闩。控制操作在完成授权校验和预约后释放门闩，撤销不能回滚已受理操作。只读或预览响应中已交给网络或代理的字节也可能在撤销后到达。工作台若无法为响应设置写入期限，会拒绝摘要或控制预览。后续改变授权的代码也必须遵守相同顺序。
