# 项目维护方向

项目以非营利方式维护，当前聚焦修复已有问题，不规划新增功能。

- 修复现有功能和内置 frp 核心的缺陷，改善异常处理与资源清理。
- 提高安装、卸载、升级和软件更新的可靠性，保护已有数据。
- 如实记录协议互通、多实例和安装升级的已知限制及验证情况。

0.8 系列持续修复；源码变更不等于已完成运行验收。实际发布版本和安装包以 [Releases](https://github.com/Presikid/KurumiFrp/releases) 为准。

## 早期版本历史

以下仅记录当时的开发背景，不代表当前功能或后续计划。

### 0.2 更新

已加入官方核心下载/校验/版本切换、用户级安装器、四平台预编译包、短时浏览器登录票据和本机自动端口选择。
安装器提供工作台自启动入口；实例也可逐个选择在工作台启动时自动恢复，启动前执行配置校验并显示失败原因。下载进度是真实字节数，不是模拟。


### 0.3 更新

已加入分发文件清单、内容验证的安装包自动清理、公开仓库在线安装脚本，以及 Windows/Linux 当前用户清洁卸载。原安装、进程停止及残留检查由 CI 验证。卸载的清理范围是本安装拥有的应用文件和系统集成项，不包含系统或浏览器取证记录。

### 0.4 原生安装

发行目标改为 Windows Setup.exe 和 Linux DEB/RPM；旧脚本/便携式发布流程停止，旧 tag 保留。
