# 批量导出规则配置

管理员可在规则列表选择当前筛选中的规则，点击「导出选中配置」并确认下载。请求绑定当前草稿修订号；草稿变化后需刷新并重新选择。ZIP 不加密，TOML 中包含明文客户端认证令牌、所选规则的配对密钥和 HTTP 密码，应像密码一样保护文件并避免公开分享。

每个所属客户端生成一个 `frpc-<实例ID>.toml`，文件注释标明客户端名称、ID 和草稿修订号。每份文件包含该客户端的连接配置和属于它的所选规则，不包含未选规则；所选停用规则保留为 `enabled = false`。应使用支持该字段的 frp 客户端，当前内置核心支持。导出草稿不会启动实例，也不代表代理注册成功或服务可达。

XTCP Visitor 的回退目标须同时选择，并属于同一客户端；已启用的 Visitor 不能指向已停用的目标。停用的 Visitor 也须包含完整、无循环的回退链，避免后来启用时缺少依赖。若依赖不满足，整个导出会报错，不会生成不完整文件。

TOML 中字符串的花括号以 Unicode 转义，避免 frp 的 Go 模板处理把原始值当作模板执行；TOML 解码后仍是原值。最多选择 512 条规则，解压后的配置内容最多 16 MiB。文件名使用系统生成的客户端 ID，而不使用实例名称作为路径。
