# 服务端控制入口来源限制

编辑服务端实例时，可选择只允许或阻止指定的 IPv4、IPv6 地址及 CIDR 网段。每行一项，也可用逗号分隔，最多 128 项；允许或阻止模式至少需要一项。关闭限制并保存会清空列表。修改保存在实例草稿中，重启应用后才对新运行代次生效；已有的客户端连接会随实例重启断开。

该规则由内嵌服务端在处理 frp 控制入口连接时检查直接网络对端，覆盖进入该处理流程的控制、工作和 visitor 连接。不能从转发头推断来源；经过反向代理、NAT 或隧道时看到的可能是中间节点。无法解析成 IP 的对端会被拒绝，包括没有网络对端地址的内部连接。IPv4 映射的 IPv6 地址按 IPv4 匹配，普通 IPv6 网段只匹配 IPv6；如要覆盖所有来源，需要分别填写 `0.0.0.0/0` 和 `::/0`。

这不是系统防火墙：规则不会过滤公开代理端口、P2P 数据流或其他服务，也不在内核或 Docker NAT 前执行；部分握手发生在规则检查之前。对公开代理端口或整个机器的访问限制仍需另行配置系统防火墙。运营商 ASN、动态地址列表与被阻止连接的实时统计尚未实现。

此规则只适用于本项目的内嵌运行后端，不是 frp 原生 TOML 设置。配置预览中的注释只是说明；将 TOML 单独交给其他 frps 运行不会执行该规则。外部兼容后端或未显式支持此规则的运行后端会拒绝启动启用了规则的实例，避免静默忽略。
