# UDP 数据报接收缓冲

客户端和服务端实例均可设置 `udpPacketSize`，用于 UDP、SUDP 规则及 SUDP 访问端的数据报接收。填写 0 使用内置核心默认的 1500 字节；填写 1–65535 可指定字节数。65535 是工作台的范围限制，不是上游 frp 对该配置规定的上限。

应将同一链路中相关的客户端、服务端及 SUDP 访问端设置为相同的值。数据报大于接收缓冲时可能被截断，设置得过小会影响应用数据。客户端按活动来源分配缓冲，队列中的数据报另占内存；高并发和大尺寸可能显著增加内存，该值不是实例内存上限。它也不是网络 MTU，不会改变路径 MTU、系统网络配置或保证数据报能够送达。

保存实例只更新草稿，须重启相关实例后生效。非零设置会写入实例生成的 TOML；0 会省略该项，由核心使用默认值。导入支持同名的顶层 `udpPacketSize`，缺省时使用默认值。较旧的编辑器如果没有提交此字段，保存现有实例时会保留已保存的值。

内嵌核心的 UDP/SUDP 协议互通、不同平台和异常清理仍需运行验收；仅保存或通过配置检查不能证明实际流量正常。
