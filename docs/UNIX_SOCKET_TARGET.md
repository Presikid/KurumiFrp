# TCP 规则的 Unix 域套接字目标

TCP 代理规则可以选择 Unix 域套接字作为本地目标，填写以 `/` 开头的路径，例如 `/run/service.sock`。当前不接受 Windows 盘符路径；在 Windows 上，这类路径能否使用还取决于系统和运行环境对 Unix 域套接字的支持。保存规则后重新启动客户端实例应用；工作台进程账户必须有访问目标套接字的权限。

内嵌客户端使用 frp 的 `unix_domain_socket` 插件连接目标，并把套接字连接纳入当前客户端代次的生命周期。PROXY 协议、加密、压缩和带宽设置仍按 TCP 规则配置。

可以为 Unix 目标启用连接式代理自动健康检查，并设置超时、检查间隔和连续失败次数；填写 0 时沿用默认值。每次检查会尝试连接套接字并关闭连接，只能反映当时能否建立连接，不验证应用响应或公网可达性。连续失败达到阈值后暂停代理，恢复后自动重新注册。Unix 目标不支持 HTTP 自动健康检查或工作台手动本地检测；切换为 Unix 目标时，如果已选 HTTP 健康检查，须明确改为连接式检查或关闭。修改草稿后需要重启客户端实例才能应用。

支持导入和导出包含 `plugin.type = "unix_domain_socket"` 与 `plugin.unixPath` 的 TCP 代理；连接式检查使用 `healthCheck.type = "tcp"` 及对应的可选超时、间隔和失败次数配置。开发中的 SOCKS5 插件及其边界见 [SOCKS5 插件](SOCKS5_PLUGIN.md)；其他客户端插件尚未开放。Unix 套接字的协议互通、健康检查与异常回收仍需进一步验收。
