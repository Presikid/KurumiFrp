# 版本约定

项目版本使用 `a.b.c.d` 四段数字，当前版本是 `0.7.1.19`。标签使用 `v` 前缀，例如 `v0.7.1.19`。各段取值为 0–65535，以兼容 Windows 安装程序版本字段。

- `a`：超级大版本，由项目负责人决定；推进时 `b.c.d` 归零。
- `b`：功能大版本，由项目负责人决定；推进时 `c.d` 归零。
- `c`：一个功能板块中的小板块完成时推进；推进时 `d` 归零。
- `d`：每个新 PR 默认推进一位。

并行 PR 可能基于相同的旧版本；整合时以最新目标分支为准，调整版本号并同步程序、安装包、界面、测试和发布说明。`VERSION` 和 `internal/version/version.go` 必须一致。

版本比较按数字逐段进行；为了识别旧版本，更新器将旧三段标签视为末段为零。已发布的 0.6.0 更新器不能识别四段标签，首次升级需要手动安装对应的原生包。PR 合并到主分支后，GitHub Actions 会先构建并检查安装包，再发布对应版本；也可以在需要时手动运行发布流程。已存在的发行版不会被覆盖。

发布说明直接写更新内容，不重复发布标题中的产品名和版本号；自动检查会阻止重复的标题。
