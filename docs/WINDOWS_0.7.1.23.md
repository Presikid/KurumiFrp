# Windows 安装、更新与卸载

安装需要管理员授权。安装完成后，请登录平时使用的 Windows 账户，从开始菜单以普通权限打开 KurumiFRP。

已登记的机器级安装会沿用原目录，包括自定义目录。旧 ProgramData 资料通过安装记录和权限检查后继续留在原位置；如果新旧目录同时存在或资料无法确认，安装会停止并保留数据。

从旧版工作台发起的静默更新可能无法显示最终结果。请在安装结束后手动打开工作台，核对版本和配置。新版本的更新入口会显示安装向导。

卸载前请先关闭所有账户的工作台和连接。新版卸载器保留账户数据；重装时选择原安装目录，安装器会检查记录后接回资料。卸载后自定义目录不会被自动发现，选择不同的空目录会创建新的配置。

安装中断后，先备份安装目录中的 runtime 和仍存在的旧 ProgramData 目录，核对文件与配置后再处理。维护标记存在时程序可能拒绝启动；不要直接删除未知资料或标记。旧版卸载器文件可能仍在安装目录，请使用 Windows 设置中当前登记的卸载入口。
